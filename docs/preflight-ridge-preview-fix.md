# 前置轨迹断段与绘线修复（2026-11-24）

## 根因与修改

- `propose_pairs` 原先在 `gap_review_applied` 后直接返回原片段。缺口审核只处理较长缺测，导致相邻或轻微重叠的片段也失去原有拼接机会；中央主线的尾段成为竞争配对，截图样本出现第五个伪身份候选。
- 恢复相邻片段拼接；仍保留重叠点、角度一致性及数量预算门限，已审核的超过 20 秒缺口不由此通道重新拼接。
- 图像细化不再永久锁定初始直线模型：训练方位拟合残差超过 0.25 度、训练测量至少 30 个时，额外比较有限的双轴谐波初值。留出测量不参与初值生成或升级判断，最终仍由留出像素和模型复杂度选择。
- 期望 BTR 原先把 2%～98% 时间采样拉伸到整幅 ROI；现在按实际采样时间插值，未观测的时间边缘保持黑色，不冒充测量。
