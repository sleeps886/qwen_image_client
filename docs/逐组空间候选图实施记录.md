# 逐组空间候选图实施记录（2026-11-26）

## 用户变更
右栏主图改为计算并展示空间轨迹，而非方位—时间图。v1.1冻结方案原文不变；此为其后的明确展示/计算需求变更。模型未来预测及原独立空间绘图调用保持不变。

## 实现
- 新增sequential_spatial_preview.py，从working_view已可见输入组计算；未处理未来组、来源分组、真值文件不参与。
- 沿用spatial_tracks的阵列位置/前向射线交会函数，使用平台起点、恒航向恒速、船体/拖曳阵偏移及同步双阵方位；所有平台使用首平台起点的统一局部东/北米坐标。
- 相对折叠方位保留h/t正负手性分支，不按真值挑镜像。不把镜像当新增目标。
- 一个双阵输入组就可给条件交点，不以“至少5时刻身份核对”限制原始几何候选；但明确标明输入双阵同目标配对尚属假设。
- 只有双阵均有关联归属、前后两阵都有程序保存的接续边、交点稳定且同分支时才连空间候选线。不同目标、未归属、未校验、缺边/缺时刻不强连。
- 对同组已指向不同目标的双阵不交会。缺阵、缺平台、基线不足1米、前向射线不交/夹角不足0.05度/距离超过100千米均返回说明，不补距离。
- 敏感性按明确bearing_error_assumption_deg计算；未提供时沿用±1度假设。峰宽sigma_deg不当作定位误差，默认值不是统计置信区间；不因simulation_ideal标签自行设误差为0。
- 扰动交点不存在或最大位移超过min(5000米,距离50%)时，仅显示名义交点空心标记，不连可靠轨迹。阈值是工程敏感性筛查，非真实准确率验证。
- 右栏主图改为空间轨迹/逐组几何候选，等比例米轴、平台方块、镜像图例；支持缩放/复位/拖动和完整双阵悬停。原方位图折叠为诊断，不当空间路线。
- 运行接口增加working_view.spatial_preview及健康能力标记；旧已校验片段可只读派生显示边，无需重跑模型、不修改旧队列策略或原始状态。
- 本地计算不产生额外模型调用，不是未来轨迹预测；原模型空间预测仍须单独授权。

## 使用
等当前调用完成，重启后端、Ctrl+F5，再点击刷新状态（免费）。已有逐组数据可直接得到本地空间候选，不需要重新付费执行。
若只有空心点或缺项说明，应检查配对、阵列基线、视差及实际角误差；不能靠连接方位点补出可靠距离。多平台姿态动态/转弯导航尚非本配置的恒航向恒速模型，必须提供相应导航模型后另行扩展。
