# 关联输入与回复协议优化

## 目标与边界

优化“本地候选参考 → 模型联合关联 → 回复校验”，不恢复固定点数上限，不删除原始观测，不增加自动调用、分批调用或失败重试。人工确认集合和第二次绘图授权保持不变。本次未使用真实模型测试。

## 主要修改

### 1. 无损表格传输

- 领域层继续保存完整规范上下文，免费预览、摘要签名、历史复核和原始点位均不改变。
- 仅预测专用网关在识别到 `mixed_observation_association_v2` 时启用 `association-table-v1` 传输。普通图片、旧版单阵预测和第二次绘图不转换。
- 观测只注册一次；表头和公共字段只写一次，历史、候选片段与接续边使用明确的行号引用。未缺省数值、未四舍五入、未截断候选或观测。
- 可选字段存在位掩码区分缺失与null；布尔与数字等JSON类型不混合。离线解码能完整还原规范上下文。
- 免费准备显示点数和压缩前后提示词字符数；它们不是token数，也不包含HTTP结构及通用system消息。

### 2. 紧凑回复与安全解码

新回复格式为 `association-compact-v1`：

- 优先用候选片段 `candidate_ref`，自组片段则返回 `point_indices` 整数数组，而不是手抄长O编号。
- 行号是本次传输观测表的1-based行号，只能引用本轮允许分配的点；历史行不得借此新增分配。
- 理由使用固定 `reason_code`，程序解码为中文候选解释，不要求模型输出长篇自由文本reason。
- 编号、行号、片段占用、跨阵证据、版本和目标片段数量继续校验。越界、布尔行号、未知理由代码和混合引用冲突均拒绝，不补零、不猜测归属。
- 旧版观测编号和reason格式继续兼容。原始模型正文完整保留；解码不是修改模型原文。
- 无证据时可明确不给轨迹，所有未归属点仍保留，不强行凑目标数量。

这属于明确的序列化与回复契约，不是供应商原生约束解码。没有添加可能不兼容的JSON-schema供应商参数，也不能保证模型永不违反协议。

### 3. 候选证据分级

RANSAC参考增加支持点数、拟合参数数、`in_sample_only` 和候选证据级别。只有4个支持点的二次拟合标为 `weak_four_point_quadratic`。低样本内RMSE不再在输入中缺少风险解释，但它仍是候选而非身份答案；没有删掉原始点或自动确认目标。

### 4. 错误诊断与旧版检测

- 输出额度/上下文耗尽明确分类为 `model_output_truncated`，执行节点显示被截断而非只有ClientError。
- 不存在的R候选、超出当前协议的目标片段数明确指出位置和约束。
- 检测到后端尚未加载紧凑传输版本时，页面提示重启并阻止旧版付费发送；本地浏览、历史读取和免费操作不会自动重发模型。

## 离线复盘结果

同一轮100个已选观测：原已保存模型输入49,813字符；使用新参考风险标注及紧凑传输后19,420字符，较原输入减少约61%。新规范上下文本身为52,234字符。解码后与新规范上下文逐字段相等，100点、所有数值与参考关系完整保留。

旧失败回复中的 `O00011` 仍被拒绝，没有因优化而自动补成其他编号。没有采用或修改任何已保存的真实失败结果。

这里只测量字符量及协议行为，不能换算成真实token节省比例，也没有验证真实模型耗时、准确率或成功率。

## 使用

先等正在执行的调用结束，再重启工具并刷新页面。选择点位，点击“准备输入（免费）”，查看完整保留点数与传输字符量；确认后仍需自行授权发送。已有失败调用不会自动重跑，也不能用本次改动补造被截断的正文。
