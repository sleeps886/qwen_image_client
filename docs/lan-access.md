# 局域网访问

本机 WLAN 地址：`192.168.1.230`，服务端口：`8870`。

项目 `.env` 已将 `APP_HOST` 改为 `0.0.0.0`，并将 `192.168.1.230` 加入 `APP_ALLOWED_HOSTS`，保留原本机白名单；模型密钥不变。重启服务后，本机和同一局域网用户可分别访问：

- 本机：`http://127.0.0.1:8870`
- 局域网：`http://192.168.1.230:8870`

## 首次放行 Windows 防火墙

右键项目根目录 `enable_lan_firewall.cmd`，选择“以管理员身份运行”。当前普通进程无法添加防火墙规则。

脚本仅开放 WLAN 接口、本机指定 IP、TCP 8870、来源 LocalSubnet；不关闭防火墙、不修改网络类别、不做路由器公网映射。WLAN 当前为 Public，因此规则适用于全部配置文件，但仍受接口、地址和本地子网限制。只在可信网络启用。

管理员撤销命令：`Remove-NetFirewallRule -Name QwenImageClient-LAN-8870`。

## 限制

- 电脑需开机、服务保持运行，访客需连接同一局域网；路由器访客隔离/AP 隔离可能阻止连接。
- 本项目没有用户登录和权限隔离，局域网访客可查看历史结果、上传文件及提交任务；模型调用共用服务器额度。勿向不可信网络开放，勿做公网端口转发。
- DHCP 地址变化后需同步 `.env` 白名单及防火墙脚本的 LocalAddress；建议在路由器中保留 DHCP 地址。
- 浏览器使用 LAN 地址打开页面即可，前端请求为同源相对路径，不需要开放跨站 CORS。
