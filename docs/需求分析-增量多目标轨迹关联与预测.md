# 增量多目标轨迹关联与预测——需求分析

版本：1.0　日期：2026-11-25　编制：小怪

状态：**需求与设计基线，分阶段实施中**。本文现状章节保留编制时基线，不代表功能已全部完成。后续实际改动与验证见[实施进度](实施进度-增量轨迹.md)。

配套文档：[技术方案](技术方案-增量多目标轨迹关联与预测.md)。

## 1. 背景与问题定义

项目现有轨迹工作台用于导入方位观测、提出关联集合、人工确认，再独立授权模型绘图。测试阶段可以提供随机散点、前中后段混合数据；真实场景可能单点到达、成批到达、乱序补到、单阵先到而另一阵后到。需要识别不同物理目标的轨迹，允许证据逐步积累、竞争、修订，而不是只处理一种固定形态的数据。

**不得把完整历史数据、严格双阵同步、固定点数或固定时间连续性作为接收与关联分析的统一前置条件。**缺少某种证据只限制能够得出的结论，不自动使观测无效。

### 1.1 本次确认的业务原则

1. 随机、稀疏、单点、批量、乱序和缺阵均为有效业务输入形态。
2. 新点应与已接收历史、未归属池、待决关系共同分析；不能每批独立重新建目标。
3. 一个新点可能借助充分历史证据可靠接续；不能机械要求每批都包含多个点或同步双阵。
4. 先暂存、先提出假设、后续再修订是正常行为，不等于执行失败。
5. 同阵片段、跨时段片段链、物理目标假设是不同层级；片段数、阵列数、文件数不是目标数。
6. 接收观测不收费；抽样、免费准备、状态刷新、查看旧结果不得触发模型调用。
7. 默认只按用户对具体输入快照的授权调用云模型；不自动重试、不偷偷拆成多次付费调用。
8. 正式预测和模型绘图保持独立授权。没有空间可观测性时可分析方位片段，不能补造距离。
9. 来源文件与参考真值不是模型关联依据。已知标签实验必须单独标识，不混入盲关联评估。

### 1.2 对前期方案的修正

“先按同步时刻整组抽样”仅作为**可选测试模式**，不是普适入口规则。现有按单点随机抽样仍有测试价值，应准确标明单位、保留抽样记录，而不是为了让算法好看强行补成双阵输入。

没有严格同步不代表数学上永远不能定位；当前代码的同步几何路径与未来异步运动约束路径必须分开。后者在实现及验证之前不得宣称可用。

## 2. 范围与非目标

### 2.1 本期范围

- 沿用 FastAPI、Python 数值计算、原生 JavaScript、现有模型网关和本地工作台。
- 当前重点是单平台、多目标、hull/tow观测；平台位置和阵列几何作为独立配置。
- 支持真实追加观测、混合批次、本地证据更新、模型辅助关联、人工确认、预测版本追溯。
- 保留JSON/ZIP导入、来源分组浏览、现有紧凑模型协议、完整流式正文和历史任务。
- 建立单点、异步、乱序、批次变化、交叉与断段等可复现的验收基准。

### 2.2 不在本期承诺中

- 任意方位观测均存在唯一空间解，或保证100%目标识别正确。
- 根据文件名、生成器目标编号或真值直接替模型确定目标。
- 未经验证的跨平台身份融合、时钟自动校正、传感器误差自动标定。
- 把本地线性外推伪装成模型预测，或在模型失败后悄悄换算法生成正式结果。
- 无费用授权的自动云端分析、自动重试、进程重启后自动继续付费。
- 本文发布即代表已经形成可用于安全关键决策的生产系统。

## 3. 术语和数据口径

| 术语 | 约定 |
|---|---|
| 原始观测 | 一个真实测量点，具有编号、观测时间、平台、阵列、方位及可选质量信息 |
| 同步时刻组 | 同一平台、同一已解释时间下的候选集合；可含多个hull或tow点，不等于目标配对 |
| 接入批次 | 一次收到的数据，可含1点或多点；仅是传输边界，不是目标身份边界 |
| 来源分组 | 原文件/ZIP或已有目录中的浏览分组，只用于追溯、筛选和实验组织 |
| 片段 | 同平台同阵列、若干观测支持的局部方位轨迹候选 |
| 片段链/同阵集合 | 可能属于同一目标观测过程的多个兼容时间片段，允许断段 |
| 物理目标假设 | 对片段链身份关系的可修订解释，不因人工采用而变成真值 |
| 未分析 | 尚未纳入本次分析快照的有效观测 |
| 待证据 | 已纳入分析但暂不足以确定归属的观测，不等同于杂波 |
| 待决/歧义 | 存在多个可行归属，暂不作唯一决定 |
| 因果预测 | 仅利用指定发布时刻已经到达、且未晚于预测起点的观测生成的未来估计 |
| 事后重建 | 利用后来到达或更晚观测修订历史轨迹；必须与当时的预测区分 |

“100点”默认指100个单独观测，不能称为100组双阵；“100组同步时刻”可能含远多于200点。界面必须明确单位与实际数量。

导入多个ZIP也不能仅凭平台配置相同就推断同一场景或同一时间轴。来源时间基准不明确时可分别接收，待用户/采集端建立映射后再联合关联。

### 4.1 已观察案例的正确解释

某轮完整数据1224点、170个双阵完整时刻；按单点抽取100点后，包含52个hull、48个tow、100个不重复时刻，没有严格同步时刻。候选参考覆盖40点，最后形成2个片段、8点接入、92点未归属。

这说明：抽样单位与可用证据需要展示；不能将“阵列数量平衡”当同步，也不能把低归属率当作数据无效、没有目标或必须强制同步的证据。测试输入本来就允许稀疏、乱序和缺阵。

## 5. 场景需求

| 场景 | 应有行为 | 不允许的行为 |
|---|---|---|
| 无历史时只来1点 | 接收、展示、暂存，给出当前可分析范围 | 以不足双阵为由丢弃；硬造完整轨迹 |
| 有充分历史时来1点 | 与历史链、待决分支比较，尝试接续并更新证据 | 每来1点都重新建立目标或只看本批 |
| 一次来一批 | 批内与批间联合考虑，保存批次边界 | 默认每批独立、直接重置会话 |
| 后段先到，前/中段后到 | 保留到达顺序；局部历史复核、新版本说明 | 覆盖当时预测，冒充早已知道后续信息 |
| 两阵先后到达 | 先分别接收；后续匹配或积累异步运动证据 | 等待另一阵前不接收，或假装同时测量 |
| 随机分散测试点 | 按真实证据能力分析；允许竞争和待证据 | 自动改造成连续输入后宣称原输入识别成功 |
| 重复到点 | 幂等识别同一观测，保留必要接收审计 | 重复计数为支持证据或重复调用模型 |
| 相同编号但值不同 | 明确冲突/修订关系，隔离待核对 | 静默覆盖原值 |
| 模型运行中继续到点 | 新点持久接收，当前云快照不变，显示待分析队列 | 新点被旧结果覆盖、自动触发第二个付费请求 |
| 等待人工确认时到点 | 同样接收；确认只针对原快照 | 让新点无故丢失，或把旧确认说成覆盖全部新数据 |
| 目标交叉/断段/转向 | 保留竞争、分裂/合并谱系及不确定性 | 仅凭最近点、缺测间隔或片段数量决定身份 |

## 6. 功能需求与验收

| 编号 | 功能要求 | 核心验收 |
|---|---|---|
| FR-01 | 支持单点、批次、随机、乱序的统一接入 | 1点和混合批次均有明确接收结果，不重建已有会话 |
| FR-02 | 校验、幂等、冲突隔离 | 同点重复接入不新增证据；同请求不同载荷报冲突；错误点不吞掉同批合法点 |
| FR-03 | 观测时间与到达时间分离 | 每点保留观测时间、时间基准、服务器接收时间及顺序号 |
| FR-04 | 可选测试抽样与明确单位 | 保留按点随机；可选同步组/窗口抽样；不修改或丢失原始点，不强制补阵 |
| FR-05 | 累积历史增量关联 | 新点能与已确认链、未归属、待决集合共同比较；批次不是身份边界 |
| FR-06 | 假设竞争与目标ID管理 | 支持暂定、待决、采用、撤回、拆分、合并及谱系；不把片段数当目标数 |
| FR-07 | 跨阵与能力分级 | 同步是证据类型而不是入口门槛；单阵可分析；异步空间能力未验证时明确降级 |
| FR-08 | 预测/重建及知识边界 | 预测记录输入快照与两个时间截止；后验重建不冒充原预测；无依据不输出确定距离 |
| FR-09 | 迟到补点及局部回放 | 迟到点触发本地影响范围分析；旧预测保留，新结果有父版本与修订原因 |
| FR-10 | 人工确认与订正 | 确认范围精确到快照；旧确认可被后续证据挑战，但不静默修改 |
| FR-11 | 费用授权和防重复调用 | 关联与正式预测分别授权；相同分析请求不重复发送；未知调用不自动重试 |
| FR-12 | 流式展示与断线恢复 | 完整正文追加、分阶段状态、只读重连/刷新；服务重启不伪装成已完成 |
| FR-13 | 质量审核与解释 | 未分析、待证据、歧义、已采用分别统计；低覆盖只告警，不强迫归属 |
| FR-14 | 持久化与并发接收 | 分析/确认期间可继续接收；观测与投影不会相互覆盖，冲突有可见结果 |
| FR-15 | 真值隔离与盲评 | 文件来源不直接当身份；真值只进入隔离评估，不进入关联快照与模型提示 |
| FR-16 | 平台与时钟配置版本化 | 缺配置仍可接收观测；变更配置有版本，旧结果保持原依据，不混用不同时钟 |
| FR-17 | 导入、导出和数据治理 | 保留现有文件库操作语义；完整原始数据、分析范围、结果和版本可分别导出 |
| FR-18 | 资源可见与范围可控 | 不恢复256/4096等固定选点门槛；大数据压力显式提示，不偷偷删点或拆付费轮次 |

### 6.1 归属状态口径

原始测量与归属投影分开管理。原始测量可以有效、隔离、存在冲突或被显式修订；有效测量在某分析版本中可以未分析、待证据、待决、暂定接入或被人工采用。后续撤回归属不等于删除原始测量。

每个分析快照必须解释所有纳入点的去向。没有被选入该快照的点只记“未分析”，不能笼统算入模型的未归属率。确定接入、待决、待证据等最终统计互斥，候选竞争阶段可有多个假设但必须声明竞争。

### 6.2 预测能力的表达

- 无有效运动证据：仅展示实际观测及缺项，不强行预测。
- 有单阵时序/历史支持：可形成方位趋势或候选延续；正式预测仍遵循授权，不补距离。
- 有跨阵/运动几何支持：可提出空间候选，但必须保留镜像、多解和不确定性。
- 不得把模型自报“高置信”当作校准概率；未校准时使用证据等级和风险说明。
- 新来1点可以利用已有充分历史升级能力，不要求当前批次独立满足全部证据条件。

## 8. 关键验收矩阵

| 编号 | 用例 | 判定重点 |
|---|---|---|
| AT-01 | 空会话先接收单个hull点 | 点不丢、不要求tow，状态和能力说明正确 |
| AT-02 | 已有轨迹后逐个到点 | 历史被使用，不每点新建目标；未经授权0次云调用 |
| AT-03 | 相同数据分别按1点/随机批次到达 | 账本有效测量一致；同快照本地证据可复现，模型结果不承诺逐字相同 |
| AT-04 | 先后段，再前段/中段 | 原预测不变，回放范围可见，新旧版本可比较 |
| AT-05 | hull先到，tow延迟到 | 先单阵保存，后更新同步/异步证据；不伪造同步 |
| AT-06 | 只有单阵且长期缺阵 | 可分析/暂存，空间能力明确受限，不抛弃整批 |
| AT-07 | 同批同平台同时间多个候选 | 不按列表顺序或强度强配目标，保留竞争 |
| AT-08 | 重复提交/请求超时后重发接入请求 | 观测幂等，模型不自动发送；相同键不同载荷报冲突 |
| AT-09 | 云调用或人工确认期间继续到点 | 新点持久化；旧快照、已有确认与新队列范围不混淆 |
| AT-10 | 更新平台参数或时间基准 | 旧结果仍引用旧版本；不兼容配置不直接混合 |
| AT-11 | 交叉、断段、折返、恢复可见 | 记录误拆分/误合并/身份切换，不能预定正确目标数 |
| AT-12 | 随机采样100点与同步组采样对照 | 单位清楚，原始点保持不变；前者不会因缺同步被拒绝 |
| AT-13 | 所有点暂缺证据/归属很少 | 仍是有效分析结果，但不能显示目标已全部识别或可空间绘图 |
| AT-14 | 断开页面、重连、刷新 | 同一云调用次数不增加；已完成结果可读取 |
| AT-15 | 服务在发送前/发送后停止 | 未确认外部结果保持unknown，不自动再次发送 |
| AT-16 | 提示词/回复含真值或错误引用 | 真值隔离、非法行号和重复占用被拒绝，原文保留 |
| AT-17 | 历史时刻预测时已知更晚观测 | 更晚事件不进入因果预测；事后重建另行标记 |
| AT-18 | 大批数据、导出与删除来源文件 | 没有静默裁剪、重复计费或错误覆盖；删除范围有明确说明 |

以上是待实施系统的验收要求，不是已执行全部通过的结果。

## 9. 评估口径

### 9.1 工程正确性硬指标

- 合法观测接入留存率100%；不因缺阵或缺连续性丢点。
- 相同幂等请求不产生新测量或新的供应商发送；未知结果不自动重发。
- 每个分析版本内确定归属重复占用为0；所有纳入点有明确去向。
- 旧预测、原始观测和既有版本不被后来数据静默覆盖。
- 真实付费调用数量可审计；测试不得默认使用真实模型。

### 9.2 识别质量指标

评估误合并、误拆分、身份切换、错误接续、正确关联、未决比例、有效时间覆盖；有独立真值时评估方位/空间预测误差及相应样本覆盖。未决不是天然错误，不能以强行归属抬高覆盖率。

必须同时报告结果质量、可分析样本范围、拒绝/降级原因和费用。不同模型、参数、采样种子、到达顺序和批次方案分别记录。真实模型指标门槛待建立基线后确定，不预先承诺固定准确率。

## 11. 待确认但不阻塞文档的事项

1. 真实数据时钟、采样频率、误差标定与单位；缺失时保留原始时间，不推断同步。
2. 首期设备规模、峰值流量与目标本地性能；需要用户实测数据后确定数值SLA。
3. 异步空间解算适用条件、运动模型与误差评价；未验证之前只作为研究/实验能力。
4. 已确认结果是否需要额外操作员权限、长期保留与物理删除政策。
5. 真实模型试验额度与评价门槛；没有明确授权不得开展付费试验。

## 12. 实施原则总结

**先接收事实，再积累证据；允许暂定与竞争；限制结论强度，不限制合理输入形态；修订可追溯，预测不能穿越知识边界。**
