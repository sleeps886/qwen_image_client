# 本地反演120秒超时修复

日期：2026-11-18。

## 原因

截图的选择正确：完整正向反演、无云端复核、两张原始图及平台参数。失败不是上游API、模型正文或文件选错，而是本地总计算120秒预算耗尽。`全局归属与有界迭代`内的图像联合细化反复重算不变的其他目标模板和整个正规方程；机器负载变化时，这一阶段可能耗时约96秒，连同此前节点触发总预算，后续质检和绘图被跳过。

## 修改

- 缓存本轮其他目标模板、背景、Gram矩阵及右端项。每次优化只更新正在拟合目标对应的一行/一列，保留原有图像观测、代价和模型比较，不通过降低采样数或更改目标数加速。浮点运算顺序变化可能造成小量拟合差异。
- 图像细化阶段最多60秒，同时从总预算中预留15秒给后续检查/绘图；总预算仍为120秒，没有改成无限等待。
- 阶段预算耗尽时，只保留**已完整比较并接受**的更新，其余沿用先前有效候选；报告标记`optimization_status=budget_limited`，前端显示“部分优化候选”，明确不是全部细化成功。未完成的单次优化不提交。
- 用户取消及真正的总预算异常仍会中止，不会当作正常细化截止而吞掉。前序根本没有有效候选时也不伪造轨迹。
- 剩余时间不足50秒时，不发起可选云端复核，明确记录跳过，避免挤占绘图预算。
- 保存细化前的独占候选检查点，增加逐身份/运动族的真实进度。当前阶段不再只显示长时间无新事件；本地运行提示不再写成等待大模型正文。

阶段预留不是所有机器上的硬实时保证；前序已经超过总预算、用户取消、无有效候选等情况仍应如实失败。
