# 自动暂接连线与后续改线（2026-11-26）

## 用户要求
位置假设先连线，后续组加入时自动判断撤线、改接、切换候选位置。沿用现有工作台与逐组执行，不新建页面、不自动追加付费调用。

## 实现边界
这是独立的本地显示工作假设层，不是把未归属点改写成模型确认的目标。原Agent判断、数值校验和人工确认状态保持原样。界面分别标出已校验接续和本地暂接；本地线可关闭。

## 暂接与改接
1. 只使用working_view已可见且已校验的双阵组，按时间比较同平台双阵方位的速率和二阶延续误差；不读取未执行队列、来源标签、强度指纹或参考真值。
2. 默认24路有界候选划分，比较接入已有工作链/新起一条链的启发式成本，保留前三个竞争划分供内部诊断；不固定三条目标、不把所有点按时间硬串。
3. 少点时允许低置信暂接；新增点后重算当前已处理范围，旧暂接边可以撤回、拆分或改接。模型已校验的两阵接续边优先，不被本地提案覆盖；同一节点不因叠加本地线而多接父/子。
4. 同时刻、跨平台、已知不同目标身份、未校验组、超过配置长缺口不硬接。
5. 每条工作链再比较有限镜像候选路径，最多保留16条局部路径。对称无证据差异时仅使用显式左右约定；后续候选改变可重新选择早期镜像工作位置，不创建新坐标。
6. 一个组仍只画一个位置；含不稳定交点/本地暂接用橙虚线，明确不等于可靠定位或目标归属。
7. 本地划分计算上限160个可见可用组；超过后明确提示并仅保留Agent已校验接续，不阻止导入和显示点，不自动抛弃原始观测。不是无限规模全局MHT，也没有做真实概率校准。
8. 自动改线记录新增/撤回/校验升级的边及位置更换；与显示快照、左右约定、开关一起保存到当前浏览器会话，刷新恢复。记录标明用户显示切换或工作版本更新后的本地重算。
9. 长缺口阈值取队列固定配置；修改下一队列的准备表单不会偷偷改变旧队列的改线标准。

## 验证
- Node：两组先暂接；第三组到达后撤回早期误接并连接后两组；混合方位带保持多条工作链；Agent边优先；同时刻/跨平台/不同已知目标/无效组不硬连。后续唯一候选使两个早期镜像位置自动更换。输入不变，不造新坐标。
- 浏览器假网关：前三组明确未归属，仍显示本地暂接；第三组撤旧线并改接；记录保存/刷新恢复；开关生效；后端确认状态和调用次数未被显示操作改变。
- 三包20组浏览器回放：40条观测、20个位置假设、17条本地暂接线；没有强制设置目标数。此为抽样个例的显示层验证，不代表已正确识别三条真实轨迹。
- 实际模型调用仍由原队列授权，每组至多原有一次；显示重算、缩放、左右切换、改线记录均不触发额外模型调用。测试仅假网关，新增真实调用0。
- Node相关5组、JS语法及diff空白检查通过。
