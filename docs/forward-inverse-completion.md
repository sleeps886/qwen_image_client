## 2. 使用

1. 打开 `http://127.0.0.1:8870/`，刷新页面。
2. 上传同一平台原始 `hull/tow` 两图及该样本 `input/platform.json`。
3. “识别流程”选择“完整正向反演（工具原图，实验）”。自动选中 `btr_gui_v1`。
4. 点击“执行完整正向反演”。**不必勾选云端费用同意，也不需要有效模型配置**。
5. 如确实希望申请模型复核，另外勾选复核与费用同意。最多一次调用，失败不自动重试，不覆盖程序坐标。当前未做真实调用验证。

只支持显式工具原始配色及−5～16dB，单平台双阵。文件保留hull/tow名称。未知配色、理论轨迹叠加线、不同生成分布可能失败或误检，不自动声称适配。

接口：`POST /api/invert`、`POST /api/invert/stream`。multipart字段：`files`两份、`platform`一份、`renderer_profile=btr_gui_v1`、`review_model=false`、`consent=false`。模型、地址和Key只能来自服务端配置，不能从请求覆盖。

## 3. 实际九节点

1. 反演输入与标定：检索内置规则、保存约定，不加载truth/meta/参考图。
2. 完整亮带剖面测量：独立ROI、配色反查、剖面多峰与拟合。
3. 展开角路径与交叉假设：保留0/180度展开和竞争延续。
4. 双阵轨迹级关联候选：同平台同步时间与有界提案。
5. 批量运动模型反演：同时约束两阵整段方位，不逐点拼交点。
6. 全局归属与有界迭代：共享交叉测量对所有身份对称排除，不重复数量证据；再关联/拟合至多一次。
7. 可选模型假设复核：无授权时明确跳过，不伪装已执行模型。
8. 正向BTR与可辨识性检查：输出期望BTR、原图回投、残差和未解释测量。
9. 空间候选绘图与汇总：同身份同色，镜像使用不同线型；只在有测量支持的时刻输出模型估计，缺测断段。

有界预算：默认120秒、最多8峰/切片、每图20条路径、24组双阵提案、MILP5秒/1000节点；可选模型45秒请求超时。预算截断与非最优求解状态写入报告。CPU取消需要等待工作线程在检查点退出；退出前保留上传和并发槽，不提前删文件。

`inverse_fields/ridges/proposals/fit/selection/iterations/quality.json`、`knowledge_sources.json`、`execution_report.json`、`tracks.json`和预览PNG可下载。`answer.txt`明确为本地数值报告，不冒充模型正文。历史导入不新增计算或模型调用。
