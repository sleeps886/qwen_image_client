# 双阵同步配对校验

图片工作流允许隔离模型返回的异步配对，不替换编号、不修改时间、不用相邻时间补齐。调用方显式设置 `resolve_pairs(..., isolate_unsynchronized=True)`；默认调用及仅设置 `isolate_unknown=True` 的调用仍严格拒绝异步配对。

每条保留轨迹至少有两个同步且递增的合法时刻。重复使用候选、轨迹时间倒序、重复时刻、平台/阵列不一致仍报错，不通过排序或猜测规避。被丢弃的单时刻分支不占用候选。校验报告记录错误编号及两阵时间，部分结果明确保持待复核。

本地复现：源结果 `20261117_151506_6905fef2` 的 T3 有九组相差一个时间切片的错误配对；隔离后仅剩单时刻，不用于定位。离线重处理结果 `20261117_151857_f4c60833` 保留 T1 16 组、T2 8 组观测，隔离 T3 共 10 组；最终仅一个 H 身份获得空间候选定位，状态仍为 needs_review。生成图片不代表完整识别或精度达标。本次未新增模型调用。
