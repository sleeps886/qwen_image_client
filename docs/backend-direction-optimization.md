# 后端方向纠偏与未解决项（2026-11-19）

## 结论

本轮只修改后端数值反演、测量似然和诊断，没有修改前端、旋转/拉伸轨迹，
没有用参考图选择生产镜像，也没有把真值目标坐标或数量送入反演。
方向和部分位置误差改善，但未达到所有目标准确定位的要求。

输入图片 SHA256 与本地 `sample_0010/input` 一致；不是此前测试较好的 sample_0005。
两组图片和平台航向都不同，不能将两者直接当作同一次输入比较。

## 后端修改

1. `services/localization/motion_families.py`
   - 在身份关联选定之后，重新提出简单匀速、恒纬度/恒经度、双轴谐波族候选。
   - 谐波粗估不再锁死为高自由度方向；二次模型也有机会退回简单运动模型。
   - 用已有几何分支和有限径向尺度作初值；只使用训练切片，不读取标签或预设目标数。
   - 世界坐标轴运动族是工程先验，不是已知目标航向；保留自由模型及镜像。
2. `services/localization/profile_inverse.py`
   - 用训练图像挑选初值，以留出图像行的残差和工程复杂度惩罚比较运动族。
   - 非负逐行目标强度参与联合拟合，背景周期项允许有符号，避免将目标消失时刻硬绑定为片段终点。
   - 裁剪到色标上下限的像素按不等式处理，不作为精确强度参与线性背景/幅度估计。
   - 将直接截断负系数改为有界 active-set 幅度求解。
   - 竞争/混合区域掩膜在每轮优化期间固定，避免残差长度随参数变化。
   - 只有两阵支持的小幅窗口扩展可进入拟合，单阵交叉后偶然峰不能无限延长目标窗口。
3. `services/localization/observability.py`
   - 计算折叠视差与角误差代理之比，标记距离敏感目标。
   - 这是工程诊断，不是统计置信区间，也不能消除左右舷镜像。
4. `batch_inverse.py` 与 Agent 的反演节点
   - 将距离敏感信息保存到轨迹质量报告，并产生明确告警。
   - 低回投误差不再作为可靠空间位置的暗示；没有变更前端展示坐标。

原来的超时预算、取消、默认零云端调用、身份连续轨迹和观测/估计隔离继续保留。

## 试验与取舍

实验记录在 `work/direction-optimization/`，没有覆盖旧生产结果。

- 单纯扩展支持窗口使别的目标在交叉之后的单阵峰进入拟合，出现退化，已改为两阵小幅扩展。
- 初值增加径向尺度本身不能解决测量偏差，不能将其当作正确距离保证。
- 联合处理未知可见性显著改善直线/谐波方向。
- 裁剪像素和非负幅度求解降低了弱目标距离误差，但仍未充分解决短基线测距。
- 全局恒定行归一化没有带来整体收益，未采用。

弱目标仍需更准确的角度标定、测量误差建模，或增加平台机动/更长基线/独立侧别信息。
不能通过前端“摆正”、真值挑分支、强制横线或隐藏失败样本来代替这些约束。
