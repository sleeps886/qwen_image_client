# 独立线路推演工作区建设内容概要

日期：2026年11月27日  
用途：明确本次需求大致需要建设的方面、主要工作和实施顺序。  
状态：规划说明，不表示下述功能已经开发完成。

## 一 建设目标

在现有系统左侧增加独立的“线路推演”入口，采用类似Codex的布局：左侧管理文件和会话，中间展示对话及Agent执行过程，右侧展示路线和各阶段分析图。

针对一条指定目标，给定确定的起点和终点，结合少量中间观测和运动条件，生成多条可能的中间路线，由大模型评判，并支持新观测加入后的修订。

## 二 本期范围

- 一次推演最多5个输入节点，包含起点和终点，中间最多3个。
- 同组hull＋tow作为一个复合节点，原始字段保留。
- 导入文件可以包含较多数据，但本次分析只使用明确绑定的节点。
- 最多保留5条候选线路；候选数量与输入节点数量分别管理，不强行凑满。
- 原轨迹工作台保持不变，新工作区的会话、运行状态和结果独立。
- 缺少时间时只进行空间路径分析，不虚构速度、加速度或到达时间。

## 三 主要建设方面

| 建设方面 | 主要工作 | 交付内容 |
|---|---|---|
| 1 独立工作区与布局 | 增加导航入口；建设左侧文件栏、中间对话执行区、右侧可拉伸图栏；输入区固定底部 | 可独立使用的新页面，不影响旧工作台 |
| 2 文件与会话管理 | ZIP/JSON拖入、读取及校验；文件打开和导出；新建及切换会话；删除会话保留文件 | 独立文件库、会话列表和导入提示 |
| 3 节点与参数配置 | 指定起点、终点和中间节点；限制最多5节点；区分实测、条件交点和待预测内容；目标运动与平台导航分开 | 清楚、可核对的分析输入表单 |
| 4 几何与观测处理 | 统一坐标、时间及单位；计算各时刻hull/tow位置、观测方向和条件交点；保留镜像及缺项 | 中间节点双阵几何数据和观测一致性检查 |
| 5 候选线路算法 | 构建有限候选图；生成不同路线；曲线优化；检查头尾、连续性和运动约束；路线去重 | 最多5条可解释的可行候选及排除原因 |
| 6 Agent判断流程 | 编排检查、求解、评判、复核和确认节点；主模型比较候选；必要时进行已授权的质疑复核 | 可追溯的选择、推荐、竞争或拒绝结论 |
| 7 全过程图形展示 | 随节点完成展示边界图、双阵交会图、候选图、运动与观测诊断图、评判图及版本变化 | 右侧阶段图检查器，支持时刻和候选切换 |
| 8 状态、费用与异常 | 保存版本、模型原文和调用记录；授权及次数上限；刷新恢复；区分格式失败和未知结果 | 有界执行、失败说明和审计记录 |
| 9 新观测修订 | 新增中间观测后创建新版本；重新检查和比较路线；保留旧结论及改选原因 | 新旧路线对照、人工预览和明确采纳 |
| 10 测试与交付 | 本地算法、浏览器、故障恢复和真实模型测试；使用隐藏中间点独立对照 | 测试报告、使用说明、对比图和遗留问题清单 |

## 四 Agent需要重点完成的内容

### 1 分清程序计算和模型判断

程序负责输入校验、几何计算、路线生成、约束检查和指标计算；大模型负责在合法候选中比较证据、给出推荐或保留竞争，不能自行编坐标、修改指标或放宽硬条件。

### 2 明确节点流程

```text
输入检查 → 固定版本 → 几何准备 → 生成候选 → 约束与观测检查
    → 用户授权 → 主评判Agent → 必要的质疑复核 → 保存工作结论 → 人工确认
```

每个节点显示实际状态、产物和错误，不通过假进度或固定动画冒充执行结果。

### 3 固定评判依据

先检查是否满足确定头尾和物理条件，再比较中间实测支持，最后比较可信目标运动状态及不必要机动。只有头尾、缺少中间证据时，允许先验推荐，但不能宣称恢复了唯一真实路线。

### 4 控制调用与恢复

免费准备不调用模型；正常主评判1次，条件复核及结构重试须在明确授权上限内。有效待定不自动重试，网络超时或断线的未知结果不自动重复付费。人工预览、模型决定和人工采纳分别保存。

## 五 中间节点图的重点要求

按用户示例，显示指定中间时刻的目标候选位置、hull/tow阵列位置、真实观测方向、阵列到候选位置的连接线，以及附近路线。

下方列出实际方位、候选计算方位及残差。候选与观测不符时明确显示差异，不能把实际射线重新对齐候选点制造“零误差”。缺少观测、时间或导航时明确提示，不填造数值。

## 六 建议实施顺序

| 阶段 | 重点工作 | 阶段验收 |
|---|---|---|
| 第一阶段 | 独立页面、文件库、会话和五节点输入 | 能导入和配置任务，旧功能不受影响 |
| 第二阶段 | 坐标与观测处理、候选算法和免费阶段图 | 能生成并检查候选，中间节点图与数据一致 |
| 第三阶段 | Agent编排、模型评判、授权及状态保存 | 判断有证据，调用有上限，异常不重复收费 |
| 第四阶段 | 新观测修订、版本对照、人工确认和导出 | 变化可解释，旧记录保留，刷新可恢复 |
| 第五阶段 | 完整回归及真实模型对照 | 分别报告候选质量、模型选路质量及限制 |

## 七 实施前需要明确的资料

1. 起终点的位置、时间，以及是否有目标航向和航速。
2. 中间节点是实测位置、双阵观测，还是待预测时刻。
3. 目标速度、加速度和转向能力的范围及来源。
4. 平台导航、hull/tow偏移及方位定义。
5. 测量误差或明确的实验容差、允许搜索的区域。

缺项可以提示补充或明确降级，不由模型猜成确定事实。具体工期和精度目标在输入样本、参数和验收口径固定后评估，本概要不承诺未经测试的效果。

## 八 最终交付

独立线路推演页面、文件与会话管理、五节点输入、候选路线算法、Agent评判流程、全过程图形、版本修订及审计记录，以及使用说明和测试报告。
