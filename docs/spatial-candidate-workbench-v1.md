# 工作台：模型选择空间候选方案 v1

## 改动目的

修复“格式校验通过但轨迹错误”的问题：旧模式只让模型输出目标编号，前端再自己选择镜像，容易把错误归属和错误空间分支叠加。现在可在原工作台新队列中勾选 **联合判断目标与空间分支（候选方案版）**。

旧队列按原协议固定，不自动升级，不覆盖已保存原文或会话，也不影响独立文件库。此功能没有另开工作台。

## 真实处理链

1. 对本批50组和已经处理的历史计算全部条件双阵交点，不读取后续队列。
2. 数值计算竞争匀速片段、镜像候选、支持组和残差，不产生正式目标答案。
3. 准备多个互斥划分建议，对转弯前后计算“在缺口内同一时刻相遇”的残差、速度比。**没有固定三个目标**。
4. 50路单组Agent只引用当前组允许的片段编号，不再手造 `T1` 等目标编号。
5. 独立归并模型明确选择一个划分方案，并将每条链绑定到已有目标或新目标；可以拒绝全部方案。
6. 程序只展开模型明确引用的候选，校验全覆盖、同平台同时刻占用和运动约束。没有模型选择，不自动采用数值排名第一的方案。
7. 目标归属和位置分支同版本、同事务保存到快照。后续批次可修订中段和末尾。
8. 右侧图只绘制已保存的模型分支，禁用前端左右约定/最近点替换。无位置选择的组仍保留明细，不能补距离或静默丢弃。

“拒绝全部方案”是有效的待定判断，不因模型不确定而自动重试。真正结构异常仅重试失败环节，成功单组不重发；未知网络结果不自动重试。

## 本次发现并修正的具体问题

- **目标编号幻觉**：单组Agent改为从明确允许的候选编号选择，不负责建立全局目标ID。
- **转弯被当成新目标**：提供同时间交会残差，而不是仅用直线外推误差惩罚转弯。
- **共享端点误判冲突**：两段共享同组同分支的实测转弯点时允许接续、只计一次；不同分支或不同目标重复占用仍拒绝。
- **重复选片段**：提供互斥竞争划分，并要求每条链显式绑定目标，不让模型反复手抄大量点号。
- **低覆盖率伪成功**：报告覆盖、未归属、接线、误差和镜像歧义，不能用全待定或少量简单点宣称成功。
- **大请求负担**：工作历史、位置候选、片段成员和归属用无损表传输，保留完整浮点数、可选字段和全部历史；提供精确解码核对工具。

## 使用

确认没有运行中的付费调用后，重启后端并 Ctrl+F5。

1. 新建会话，可以直接打开独立文件库里的旧文件，无需重新导入。
2. 选择数据；50组快照模式下勾选“联合判断目标与空间分支”。
3. 483组正常流程493次请求；若预留20次输出重试，总上限513次。
4. 免费准备队列，检查范围、协议和预算，再勾选费用授权执行。
5. 结果仍为工作假设，最后人工核对。新功能不会把旧错误结果自动标成正确。

后端未加载新协议时会阻止启用；旧后端未支持的字段不会在未启用时随请求发送。

## 协议与代码

- `SequencePrepare.spatial_cards`：默认false，显式启用；队列固定 `spatial_association_contract=model-selected-spatial-cards-v1`。
- `spatial_hypotheses.py`：可审计数值候选、转弯接续证据、竞争划分；不读取来源身份或真值。
- `spatial_card_protocol.py`：模型协议、严格引用展开、同时间/速度检查、`spatial-cards-lossless-v1`无损传输。
- `batch_execution.py`：沿用持久化并发、预算、原文、失败环节重试和原子快照。
- `batch_position_choices`：原始观测到模型选定分支的映射；快照中使用匿名观测ID，不写来源标签。
- `spatial_preview.model_branch_choices`：按可见单元公布分支；未处理或未选择为null。
- `point-sampling.js`：`branch_selection_source=model`时不代选分支。

## 边界与剩余风险

- 这是基于几何和运动候选、由模型选择的工作归属，不是模型独自从原始散点恢复全部轨迹，也不是本地算法已确定身份后自动上图。
- 数值候选有容量和假设：每平台最多24张片段卡、最多8份竞争划分，可见单元最多1000组；支持分段匀速和转弯，不保证任意机动、杂波或未知噪声下正确。
- 默认35米残差门、100m/s接续上限是明确的保守工作参数，不是由参考答案调出的目标属性，也不是校准定位置信度。
- 静止单平台、共线双阵仍有整体镜像歧义。整条路线反射后形状相似不等于绝对侧向已确认；不能宣称真值坐标已恢复。
- 参考数据只在请求结束后做独立评估。不能用来源颜色、固定强度/峰宽或参考图替模型选择分支。
- 上游连接稳定性和模型服务限流仍是外部约束。减小请求体不代表保证50路服务稳定，不因断线自动重复付费。
