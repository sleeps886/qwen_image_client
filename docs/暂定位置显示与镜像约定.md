# 暂定位置显示与镜像约定（2026-11-26）

用户追加要求：不能因镜像未唯一解除就全部不放位置，应采用一个可撤回的位置假设。此记录取代上一轮“一组双阵一个位置显示”中严格的唯一点准入规则，不更改冻结v1.0/v1.1文档原文。

## 规则
- 每组已有有限双阵交点时，主图采用一个位置假设；无交点/缺数据才无法放置。
- 只从后端已经给出的真实计算候选中选择，不平均、补距离或外推新坐标；所有候选和原始观测保留。
- 有同一暂定双阵片段的已校验接续边时，比较当前候选到已处理工作历史（最多最后两点匀速延续）的距离。结果仅是延续工作假设，不等于独立消除镜像。
- 没有可比较历史/得分并列时使用明确的镜像显示约定：默认hull相对航向右侧优先，可切换左侧。不能把该约定称为模型判断或证据支持。
- 首个镜像种子是约定；后续基于种子的连续性也不证明初始左右为真。UI/详情/悬停明确显示采用依据和“非模型解歧结果”。
- 每组最多一个点：唯一几何、镜像暂选、不稳定暂选、未校验的展示假设分别标注。无交点仍明确说明，不虚构位置。
- 只有两阵均有已校验接续边、同片段关系且前后组已校验时才画工作假设线，不按来源或全体时间顺序强连。含不稳定交点/疑点用橙虚线，不声称可靠定位。
- 镜像约定保存到浏览器当前会话快照，刷新/切换会话可恢复；只重绘显示，不改后端模型归属、任务版本或费用，不将人为约定伪装成观测证据发送模型。

## 验证
Node覆盖：每组一点、右/左约定切换、历史优先、重合位置不重复、不稳定暂选、未校验不连、无接续证据不造线、输入不变；抽样/字段去重/预算预检回归通过。

浏览器假网关验证：真实保留两侧候选但主图两组仅两点；一个已校验工作连线；切换镜像、悬停采用依据、缩放、刷新偏好、后端状态/调用数不变，通过。没有删除一侧候选冒充真实解歧。

三个用户(2).zip抽20组模拟执行：20条组记录、40条单阵观测、40个含镜像内部候选，主图20个位置假设（无重复镜像），此次样本无缺交点组。随机抽样若无交点仍会少于20个，明确计数，不保证所有数据可定位。测试未做真实模型识别准确率评估，真实调用0。
