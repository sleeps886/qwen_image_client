# 会话与导入文件库独立

日期：2026-11-25。

## 行为

- 删除会话：只删除会话快照、当前指针及列表项；当前分析视图清空。导入文件保留，可重新打开建立会话，或导出原始点位。后端结果不删除。
- 删除非当前会话：不影响当前分析，也不影响文件库。
- 删除文件：必须明确点击文件条目的“删除”。保留原有“删除当前直接浏览文件时清空当前视图”的行为；历史会话与后端结果保留。
- 文件导入先保存到独立文件库，再载入/追加到会话。后续分析或追加失败，也不会把已经入库的文件跟着丢掉。
- 删除当前会话后移除URL的`source_result`，避免刷新时按旧地址重新创建已删除会话。

## 存储

`sonar-workspace-v1` IndexedDB升级为版本2：

- `snapshots`：会话、活动指针和用户状态。
- `point_files`：独立文件记录及显式删除标记；文件读取不依赖会话和会话列表。

升级在一个版本事务中复制旧`point-file-*`记录与删除标记。旧记录不删除，作为迁移备份；升级后文件读取以新存储区为准，不回退到旧备份复活明确删除的文件。文件列表直接枚举记录，不再依赖易被并发写覆盖的文件索引。

库升级被旧标签页占用时显示明确错误，请关闭或刷新其他工作台标签页后再试；不将读取失败显示成“没有文件”。升级失败时原记录仍保留，不自动删除数据腾空间。

这里的独立是删除生命周期和存储区独立，不等于云备份、加密或永久保存。浏览器“清除站点数据”、磁盘问题等仍可能影响本地库；重要文件请另行导出。明确删除库条目也不等于抹除所有历史快照/迁移备份。
