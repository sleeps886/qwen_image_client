# 模型断段归并成连续路径

## 截图对应问题

源运行 `20261120_162459_a01c6399`：主视图有2个身份、3个片段。N2 的同侧片段分别覆盖12～93秒及201～588秒，中间缺口108秒。后端片段来自相同全局运动假设A069，但旧缺口模型上限90秒；此外模型视图没有归并显示，同侧片段还可能被按branch顺序误编号成不同mirror_variant。

## 修改

- 数值缺口预测的上限从90秒改为120秒，与新断段关联阶段一致；仍要求相同身份、平台、侧别和运动模型，且模型与端点吻合。
- 模型mirror_variant优先按来源候选的真实分支编号，不再将同一侧的不同时间片段自动视为不同镜像。
- 最终模型视图按相同身份、已知相同侧别分组，检查不重叠时段、最多120秒缺口、双向端点运动一致性和速度工程门限；不通过时仍保留断段。
- 延续性通过的片段归并为一条显示路径，统一颜色和侧别线型。观测支持段沿用模型坐标，缺口以虚线连接端点，明确为预测。
- `tracks.json` 中 `tracks` 继续保留原始模型片段点位，新增 `continuous_model_paths` 保存归并路径，`model_display_continuity` 保存决策。未新增测量、未向准确率评价注入缺口点。
- 前端显示归并数量和缺口虚线说明；不声称定位误差同时得到修复。
