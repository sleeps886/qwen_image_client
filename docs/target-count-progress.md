# 目标数量判定、定位覆盖与节点可视化

## 执行链

LangGraph预处理：知识检索 → 像素候选 → 单阵持续亮带连接 → 数量线索 → 关联上下文。

单次模型网关：逐项目标清单（含单阵、待定、疑似杂波）＋双阵同步候选配对。

LangGraph后处理：候选校验 → 数量/未覆盖片段复核 → 双阵几何 → 连续估计 → 重投影。

随后汇总定位覆盖并绘图。模型网关与最终汇总/绘图由现有执行器调用；不能声称这三步已迁入单一LangGraph图。前后合计10个实际图节点，有界流程，不自动追加付费复核调用。

## 数量含义

- 本地使用匈牙利分配、受限角速度预测和短缺口容许构建tracklets；至少3个时间切片支持。
- 同时出现的持续片段数和总片段数形成亮带数量线索范围；两阵不相加，不直接等同真实目标数。
- 模型必须逐项审视tracklets，但可以指出疑似杂波，不能被数量线索强迫凑数。
- 单独显示：亮带数量线索、目标清单疑似ID数、已配对目标ID数、可定位目标ID数。后两者不能替代目标总数，镜像不重复计算。
- 未充分配对的持续片段、缺失清单、关联数量小于本地线索、不可定位目标均报告“需要复核”。真实目标数仍需独立数据验证，不承诺准确整数。

## 小视差处理

候选新增角误差代理：像素分辨率、局部亮带中心去线性趋势的散布、带宽项；下限0.15°、上限2°。这是工程误差假设，未经真实声呐标定，不是置信区间，也没有覆盖所有ROI/系统误差。

新证据流程把每阵代理传递至几何扰动敏感度、窗口残差权重和重投影门限。避免所有观测一律按1°拒绝：最小交角改为与误差代理相关，同时保留正向、100公里、相对敏感度50%/5000米、运动和重投影检查。旧数据缺省仍按1°处理，不声称已经提高真实定位精度。

## 前端节点过程

每个实际图节点发送running/completed/failed/skipped事件，记录真实耗时和脱敏摘要。模型阶段也显示真实开始/结束，不做假进度条。SSE流式展示，预检和历史读取展示已保存事件。

执行报告不含API Key、图片base64或完整模型提示词；未执行节点保持待执行，失败不显示成功。停止接收时前端标为已停止，不保证服务商撤销计费。断开时注销回调并取消排队事件。

新增产物：tracklets.json、target_count_report.json、execution_report.json。单文件模式保持直接数据绘图，不展示一套未执行的图节点。

## 验证与边界

合成四轨迹验证数量线索、片段/镜像去重、单阵清单不消失、漏检显式提示。模拟SSE验证26个开始/结束事件早于最终结果、节点状态/耗时、数量面板和报告下载。几何合成例验证给定小角误差时能保留真实小视差解，未放松距离/稳定性检查。

尚未调用真实模型进行A/B评测，没有真实准确率保证。交叉、杂波、弱目标、错误ROI与配对仍可造成计数/定位偏差；本地范围和模型清单可能同时出错。不得使用当前样本truth/meta/semantic作为识别知识；真值仅可进入隔离评测。
