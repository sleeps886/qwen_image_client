# 散斑、断段输入：首轮断段关联优化

## 已实现

现有高斯测量后的路径节点增加断段检测。LangGraph 使用 `add_conditional_edges`：有候选缺口时执行 `inverse_gap`，无候选时真实记录 skipped，直接进入双阵关联。

该轮不是完整的“高斯前粗分组＋高斯后复核”实现：当前检测和关联均基于已有高斯中心，尚未增加高斯前的独立粗测量节点。

- 将单条路径中大于 `max(20 秒, 2.2 × 采样步长)` 的缺口拆成片段。
- 相同图像、阵列和平台的片段，在最多120秒的窗口内建立候选；最多128对进入审核。
- 端点采用最多5个观测点的中位成对斜率及中位截距，抑制孤立散斑离群值。
- 同时检查向后、向前预测误差及斜率差；沿用折叠角展开假设。
- 接近的竞争连接标记 ambiguous，不强行选一条。原片段保留，新增最多12个跨缺口候选，链长最多4段。
- 连接仅合并原观测点，保留 `missing_intervals`；没有新增高斯测量。后续仍需双阵配对、运动拟合和排他选择，不把连接候选算作已确认目标。
- 已经过断段审核时，禁用旧的额外30秒自动连接，避免绕过审核。
- `inverse_gaps.json` 可下载；模型提示词更新到 `single_platform_fusion_v5_gap_evidence`，附带断段审计，要求按有效观测分段、不将预测点作为实测。

上述阈值是工程假设，未用这些新JPG的真值标定，不能声称定位精度或目标识别率提高。

- 合成测试覆盖：无缺口、有缺口、斜率不符、竞争片段、已有路径拆分、超长缺口、跨阵拒绝、180度折叠、三片段链、孤立端点离群值、取消、条件图路由及零新增测量。
- 原有合成图完整本地工作流通过；模型调用数为0。
- 保存的sample_0003观测重放：拆出5处原路径缺口、保留2组连接候选、新增测量0。此结果仅验证关联阶段，不是重新反演后的精度评价。
