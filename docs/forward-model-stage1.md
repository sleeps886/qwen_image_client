# 正向模型反演优化：第一阶段交付

日期：2026-11-18。此文档记录已执行的实现与验证，不代表整套反演方案完成。

## 本轮完成

1. 新增纯函数正向观测模型：显式投影参考、球面初始方位、平台运动、forward/port阵列偏移及0～180°折叠。无生成器模块导入、目标答案读取或HTTP依赖。已用固定位置、旋转/移动及投影往返测试核对；旧几何定位入口尚未替换。
2. 新增显式选择的 `btr_gui_v1` 配色测量：按工具256级配色和−5～16 dB显示假设恢复相对S/P0；标记颜色不兼容及显示边界，不称绝对强度。
3. 新增局部1～2高斯分量的有界稳健拟合：中心、宽度、相对振幅、归一化残差、截断比例、优化状态和分辨性。分量数量来自当前候选初始化，不能据此确认目标数，也尚不能保证将已合并的一个峰恢复成两个目标。
4. 免费预检可导出 `measurement_report.json` 和 `gaussian_0.png`／`gaussian_1.png`；绿色表示工程拟合条件满足、橙色表示待复核，不是目标确认/杂波结论。
5. 选择实验配置后的Agent仅收到有界质量摘要和待复核候选编号；不替换原候选角度、时间、编号及配对校验。
6. 原流程保持默认，数据文件绘图不接受实验配色参数。配色不兼容或资源预算不足时记录不可用/预算状态，不假装成功。

## 使用方法

在本地页面上传原始hull/tow图及对应platform.json，选择：

**模型前测量诊断 → 本工具原始BTR · 高斯测量预览（实验） → 仅预检图片。**

无需勾选云端同意，不调用模型；可以点击拟合叠加图放大并下载报告。仅适用于所声明工具配色、显示范围和原始图片。理论轨迹叠加、非默认配色或外部声呐图不应选择该配置；当前尚未可靠剔除所有理论线。

HTTP增加可选字段 `renderer_profile=none|btr_gui_v1`，默认none。仍使用既有 `/api/recognize` 的 `dry_run=true` 免费路径；真实模型请求的授权规则不变。选择实验预览不等于已经启用新的数值反演器。

## 工程边界

- 最多处理200万像素的实验ROI、每图最多128个拟合组；超预算明确报告，不自动增大计算量。
- 噪声过滤和候选召回仍是原有提取器；这轮拟合不能恢复原提取器完全漏掉的目标。
- 单/双峰初始化来自候选，不输出“自动准确判定两个交叉目标”的结论。
- 拟合残差、振幅对比门限及分辨性均为工程指标，不是标定置信区间。
- 显示边界像素采用单侧约束；完全饱和或有效样本不足的区域不接受拟合。
- 新正向模型组件用于后续批量反演，当前旧空间求交、运动窗、镜像分支及身份逻辑未被悄悄更换。
- 不修改仿真工具、不覆盖旧结果、不增加自动付费重试。
