# 同一目标的短时缺口连续显示

## 范围

完整本地反演仍按真实观测支持分段，不删除缺测记录，不合并目标或镜像，
不改变拟合参数。此次仅为同一空间假设提供可识别的模型推断连接段。

- `services/localization/gap_estimates.py`：按照已拟合运动模型计算缺口曲线。
- `services/rendering/trajectory.py`：画同色点线及 `Gap prediction (not observed)` 图例。
- `agents/nodes/inverse.py`：将所有镜像的推断段单独保存到 JSON，并分别绘制主图和镜像图。
- 前端图下注明连接段是模型推断，不是观测。

只有目标 ID、平台、关联假设、镜像编号和运动参数均相同的相邻分段才能连接；
端点必须与模型预测吻合。当前最多连接 90 秒缺口（工程显示限制，非精度置信保证）。
超过限值、模型不一致、时间重叠或缺少模型参数时仍保持断开。
连接段沿已有运动模型采样，不是两端点简单直线拼接；不延伸到首末观测之外。
旧模型关联流程没有这类整段运动参数，不强行自动连接其片段。

## 数据和评测

原有 `tracks[].points` 不变，推断点仅在顶层 `model_gap_estimates` 中保存，标记：

```json
{"estimated_not_observed":true,"used_for_evaluation":false}
```

推断点不增加目标数、观测时间、观测覆盖率，也不改善结构化位置评测分数。
PNG 轮廓本身发生变化，因此纯图片轮廓比较分数可能变化，不能将其当作定位改善。
空间反演、镜像选择或运动模型本身若错误，本次连接不会修正这些问题。
