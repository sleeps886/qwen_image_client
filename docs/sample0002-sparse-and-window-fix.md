## 问题一：左侧目标完全没有进入配对

原记录`20261120_110541_53106c4f`只有3个身份。T4在hull端仅形成`R0_5`共5个干净点，而tow端`R1_4`有50个连续点；两条路径有5个同步点。提案代码硬性要求至少6个同步点，因此该配对根本没有进入运动拟合。

单独对这组真实测量做拟合，得到约0.34°角度RMSE的可行候选，加入原候选后全局筛选可保留第4个身份。故不是大模型删除、不是目标不存在，也不是必须强制设定4个目标。

修正：保留常规6点门槛；仅对强弱不对称情况，允许至少4个同步点、较长阵列至少20点、短/长点数比不超过1/3、同步跨度至少30秒的候选进入原拟合校验。选中前后还必须两阵各有至少4个独占支持点，不能用单阵亮点凑空间目标。记录`sparse_dual_support`、`sparse_policy`与同步门槛拒绝数，便于复查。

完整本地重跑记录：`20261120_111048_d6007bc3`。由3个身份恢复为4个，模型调用0次。按离线最佳镜像分支核对，T1/T2/T3/T4的RMSE约53/509/422/7米；仍不是唯一侧别精度验收。

## 问题二：四个身份恢复后，右下早期亮带仍缺失

用户继续指出右下段缺失，这是有效反馈。T3虽已形成独立身份，但活动窗口仍被限制为`300～444秒`；`150～300秒`的真实回波没有进入expected BTR。仅恢复身份数量不能解决轨迹时段缺失。

原图像拟合已经用非负幅度解释各时刻的像素，但输出可见时段只根据干净峰值做最多30秒扩展。交叉/合峰时，干净峰值不足并不代表目标在原图中不可见，所以这套窗口规则过于保守。

新增双阵原始剖面的留一身份可见性检查：

1. 使用已拟合的位置/运动模型预测各目标的高斯模板，共同拟合实际图像的背景、周期项和非负幅度。
2. 每次去掉一个身份，重新拟合其余模板。只有去掉它后拟合显著变差，才认可该身份的独立图像贡献，避免把另一个重叠目标的能量重复归属。
3. 同一时刻两阵均须幅度至少0.5、相对拟合收益至少10%，并形成至少5个连续采样时刻；认可区间须与原窗口相连/重叠。只延展有像素证据的可见时段，不改位置参数，不按真值补线。
4. 原图缺少该阵能量、仅一阵有能量或两身份完全不可区分时，不扩展。阈值是工程规则，不是统计置信度。
