# X 交叉亮带关联

目标不是预先指定目标数，而是将交点前后的两条持续亮带分别关联，避免交点换线和重复取用混合峰。

## 实现

- `backend/app/services/association/crossing_tracks.py` 在原单阵亮带片段上提取非竞争连续段。
- 交点前后每段至少三次连续观测，用两侧局部切线检验位置、方向和斜率；比较两种配对，只有唯一且明显更一致的穿越解释才共享身份。
- 两条进入和两条离开亮带必须来自同一张图；两阵独立处理，不能相加计算目标数。
- 保留原始候选和模型结果。交点竞争观测不分给两条轨迹，不生成缺失角度；空间绘图仍分段，但交点两侧可保持相同 H 身份。
- 分析结果加入 Agent 上下文；真实执行摘要显示在前端已有的“单阵亮带连续性分析”节点。后处理报告 `identity_report.json` 的 `crossing_analysis` 可审计具体关联证据。

## 验证与边界

合成交叉回归测试覆盖：两个目标穿越、单混合峰、前后模型编号变化、平行线、证据不足和多种竞争解释。不读取目标真值、不更改仿真工具，也不增加付费模型调用。

这是局部连续性启发式，不是交叉目标识别准确率保证。当前候选仍是 16 个同步切片：若交点一侧缺峰、有效连续段不足三点、曲率过大或多种解释接近，保留未解状态。旧样本 `20261117_143451_9e7742a0` 和 `20261117_130247_79e1679c` 的既有稀疏候选均未通过本次唯一交叉关联条件，不能宣称它们已恢复两条真实交叉航线。后续应优先补充交叉区的图像测量支持，而不是放宽阈值或强制数量。
