# 增量轨迹实施进度

**入口修正：用户要求完善原工作台；当前日常入口统一为`/incremental`。** 持久化追加与候选链已接回原布局，原空间绘图保留，见[工作台整合修正](工作台整合修正.md)。下文早期独立`/live`入口记录仅为历史。

后续稀疏观测案例（20点、9点接入、11点未归属）的原因核对、间隔口径修正、空空间图预检及诊断展示，见[稀疏观测与空空间图修正](稀疏观测与空空间图修正.md)。未改写用户旧回复，未重新调用真实模型。

日期：2026-11-25；当前：M0及M1～M4工程链路已实施，见第5节和[v2使用与验收](增量轨迹-v2-使用与验收.md)。前四节保留M0交付时记录，不代表后续阶段仍未实施。真实模型盲评、异步空间解算与标定不作已验证声明。

## 1. 本批交付

- 取消前端导入时“同平台、同时间必须同时存在 hull/tow”的硬过滤。格式有效的单点、单阵、稀疏、异步及乱序批次均保留；重复编号和非法字段仍按原规则校验。
- 双阵完整性改为只读统计：报告同平台、严格同时间的时刻组，不代表同目标配对，不判断是否可空间定位，不作为接收门槛。
- 随机抽样默认仍按独立观测点计算，填写 100 即选择 100 个原始观测，不代表 100 对双阵或每条目标轨迹各 100 点。
- 可选“同步时刻组”对照模式：抽到组后保留组内全部候选，同时显示组数及实际点数。无同步组时仅提示切换模式，不删除或否定稀疏数据。
- 抽样只替换当前浏览范围的选择，保留其他分组已选点；不修改原始测量，不用导入文件分组充当目标真值。
- 免费准备上下文增加 `input_diagnostics`，描述本轮观测池。历史证据仍需结合已有上下文分析，当前同步计数不是历史证据总量。
- 健康检查增加 `mixed_input_policy=accept-sparse-v1`。前端遇到旧后端时阻止付费发送，提示重启升级。
- 保存并恢复抽样模式。旧过滤快照不自动扩充已分析点目录，明确提示重新打开原始文件，避免改写旧分析语义。

## 3. 使用与兼容边界

后端新增了静态资源白名单和健康标记，需结束当前真实任务后再重启后端并刷新页面。不要在真实模型运行途中重启。

旧会话仍保持旧目录和旧结果；本批不会凭过滤记录向旧会话静默补点。需要恢复此前被排除的原始观测时，请重新打开原始数据文件。

本批证明输入路径不再拒绝有效稀疏观测，不证明模型识别准确率提高或单点可定位。严格同步分组仅供测试对照，不是实际场景必须满足的条件。

## 4. M0交付时的后续清单（历史记录）

当前仍是固定点目录中逐轮选择，不是真实流式追加接入。下一批 M1 拟实施：

1. 持久化原始观测账本，区分观测时间与接收时间。
2. 空会话和真实追加入口，支持单点与批次，幂等去重及编号冲突报告。
3. 冻结分析快照；分析期间新点先落账，不改变正在执行的输入。
4. 版本及迟到数据测试，确保历史预测不使用未来证据。

滚动候选图、歧义累积与局部回溯、能力分级预测、完整评估基准仍按技术方案后续阶段实施。现有精确同步候选构造及留出验证路径的要求未在本批统一重构；不能把某一路径的同步要求扩展成全局输入规则。

## 5. 后续M1～M4实施记录

### M1：持久化接入

已新增独立`/live`工作台和`/api/incremental/live-sessions`接口。SQLite WAL账本支持空会话、单点/批次追加、逐项隔离、来源编号冲突、请求幂等、服务器接收时间/顺序、观测版本及配置版本。接入不占用模型执行锁，不因运行或待确认而清空历史。旧工作台侧栏新增入口，旧会话不自动迁移。

### M2：证据与身份投影

新增覆盖完整事件范围的重叠滑动窗口、候选链接续/竞争图、同阵多片段集合和`association-compact-v2`严格契约。每个快照内全部点必须说明去向；确定占用、待证据与歧义互斥。新点与历史/待决点角色明确传入。复用已有真实同步留出证据，异步没有伪同步。迟到点生成保守依赖回放计划，无法证明局部依赖时扩大到完整快照。

采用决定使用投影版本CAS；唯一接续保持稳定ID，拆分/合并分配新ID并记录父谱系。支持免费打回及显式撤回归属，不删除原观测或旧预测。采用只表示人工接受假设，不是真值。

### M3：费用、流与预测

授权绑定快照、摘要、模型公开配置指纹、用途和投影版本。发送意图先持久化，再进行一次网关调用。重复请求返回原任务；运行/未知任务不能通过换请求键绕过保护。手动重跑须记录`rerun_of`和重复费用确认。

运行任务与观察页面分离；事件序号支持只读SSE重连，正文按事件追加存储/展示，不逐token重写全文。重启时发送前中断标记未发送失败，发送窗口内中断标记unknown，均不自动重发。

新增独立方位预测/事后重建授权、双截止、版本化预测、旧结果对比图层。未来观测、后来采用的身份投影、后来获知的配置不会进入历史因果预测证据。空间正式输出仍保留旧工作台已验证入口；v2正式预测明确为方位能力，不假装已完成异步空间求解。

### M4：离线评估与显式迁移

新增隔离评估器：对齐不透明目标ID，统计误合并、误拆分、身份切换、接续错误与未决；真值不进入生产接入/证据/提示词路径。新增7类场景、21种种子/批次组合的工程回放基准，全部有效点保留、同一测量集候选支持可复现，0模型调用。此结果不是模型识别准确率。

显式迁移API复制测量到新账本，保存来源编号映射及只读旧结果存档；旧JSON、旧身份和预测不被原地覆盖或冒充v2已采用结果。完整账本、快照、事件、配置、投影和预测可导出。

验收命令、实际结果、旧测试失败及保留边界见[v2使用与验收](增量轨迹-v2-使用与验收.md)。
