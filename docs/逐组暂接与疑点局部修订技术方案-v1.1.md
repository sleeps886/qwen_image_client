# 逐组暂接与疑点局部修订技术方案 v1.1（冻结）

用户于2026-11-26确认：先暂接、随数据增加局部纠正。本文冻结为实现基线；v1.0原文不改，实现差异和测试结果另写实施记录。

## 1. 继承与边界
- 保留现有工作台、逐组队列、暂停/刷新恢复、执行原文、费用授权及人工确认。
- 每组1至2条同平台同时间观测，各阵最多1条。组容器不等于跨阵物理身份。
- 未来未处理数据不能进入当前模型上下文。文件来源、ID前缀和真值不能作为身份依据。
- 新策略固定到队列快照；已有运行保持原策略，不在重启时偷偷改变其调用上下文。

## 2. 流程
接收当前组 → 校验去重 → 读取已处理历史 → 准备暂接候选/疑点/修改许可 → 首组本地初始化或一次Agent判断 → 数值及范围校验 → 保存工作修订 → 右栏更新 → 后续组。

没有历史时免费建立各阵单点暂定片段。后续每组仍经过一次Agent判断；稀疏且无明显矛盾时优先低置信暂接，不因跨阵身份不足而自动停止单阵接续。明显冲突不得硬接。

## 3. 状态和协议
- 接续边记录前后点、片段、低置信/证据支持/可疑状态和版本。
- 疑点记录触发原因、涉及点和允许修改范围。
- 修订日志记录归属变化、撤回的边及新边；模型原文和原始测量不可覆盖。
- 模型继续使用现有单阵片段/目标协议表达保持、改接、拆分、新建和未归属；新增接续策略、候选证据、可编辑观测白名单及只读历史说明。
- 无疑点时只允许新增接续，不能重写旧点。有疑点时授权局部范围，范围外归属必须保持。

## 4. 疑点与有界复核
检查偏离原趋势、候选竞争、同时间占用、长时间缺口、到达乱序以及既有可疑边。两阵仍分别检查，分歧作为警告而非自动判定不同目标。

不再默认每步重放最近3组：从疑点涉及的轨迹及未归属/竞争点准备局部范围，必要时纳入关联片段支持；明确最大复核观测数。超出预算暂停，不自动截断、强连或追加模型调用。允许模型请求后续扩大复核，不能在一次回复里越权修改只读历史。已确认历史的改动仅作为待再次确认的工作提案。

## 5. 校验分层
暂接校验检查引用、唯一占用、同平台同阵、明显运动矛盾、状态版本和修改范围。
跨阵目标身份继续几何/留出证据校验；至少5个同步时刻是现有身份检验的前提，不阻止单阵暂接。
空间定位/预测继续独立能力检查和付费授权。错误提案局部隔离但不能冒充成功识别；未知引用、越权修改和版本冲突停止提交。

## 6. 图形
当前组到达即显示，一组一个hull代表点，缺hull取现有阵列，悬停含完整双阵信息。
低置信淡色虚线，支持增加后普通虚线，可疑边醒目标记；灰色未归属不强接。按相同单阵片段/目标画线，非空间预测。
局部修订更新工作图并展示修改记录；来源颜色图仅用于测试对照。

## 7. 验收
- 首组有点、第二组可低置信接续；没有物理目标也能显示方位虚线。
- 后续疑点能撤回/拆分/改接；范围外历史不变，旧确认不被自动覆盖。
- 单组/混合来源逐组回放共用流程；无来源身份或未来数据泄漏。
- 暂停恢复、旧队列兼容、原文和修订日志、调用计数可验证。
- 三个用户ZIP用离线及假网关测试；真实付费识别准确率另行授权验证，不能用校验通过替代。

## 8. 实施顺序
状态与接续边 → 有界疑点准备 → Agent提示和范围校验 → 工作图及修订记录 → 单测与三包回放 → 实施记录。
