# 一组双阵一个位置显示（2026-11-26）

用户确认：主图每组只画一个位置，未解歧明确位置待定，镜像候选放详情，不能任意选择。

## 实现
- point-sampling.js新增纯显示投影spatialDisplayGroups，按输入组unit_id汇总全部几何分支，每组只有一条位置记录。
- 同一组仅有一个稳定位置且本步已校验时，主图显示一个点；有多个不同坐标、交点不稳定、缺数据或未校验时位置待定，主图不放置候选。
- 仅合并距离小于1e-6米的数值重合交点，不平均镜像、不选最近、不按来源/真值删分支；若任何重合分支不稳定也保持待定。
- 被隐藏的候选保留在该组展开详情，包含所有分支坐标/敏感性及完整hull+tow观测。模型输入、计算结果及既有存储不改。
- 隐去待定组时不跨组补线；主图不再将两镜像画成两个目标点。平台方块仍单独保留。
- 标题显示位置点数/位置待定组数，不再用镜像点数量冒充组数。20组仍是20条组记录，不保证已有20个唯一坐标。
- “一个位置点”仍是输入双阵配对假设下的位置，不是物理身份确认或未来预测。

## 验证
- Node：镜像只进详情、唯一位置只画一次、数值重合去重、不稳定不选、未校验不放点、不跨待定组连线、不修改输入，通过；抽样/去重/预算预检回归通过。
- 假网关浏览器：原始两个镜像时主图0点、两组各一条待定记录，候选和完整双阵字段可查；使用明确的“唯一位置UI夹具”检查一组一点、连线、悬停、缩放拖动复位和刷新。该夹具只测试展示，不声称真实镜像已经解歧。
- 三包20组回放：20条组记录、40条原始观测全部保留；本次样本19组有38个名义镜像候选、1组无法定位，因此主图0个已解歧位置点，20组位置待定。候选未丢弃，没有伪造20个确定坐标。
- 浏览器仅假调用，无新增真实模型调用。JS语法及diff空白检查通过。

本轮仅前端修改：Ctrl+F5即可，不需要重启后端或重跑模型。若现有数据仍有左右镜像，界面会显示位置待定列表，而不是擅自挑一个位置。
