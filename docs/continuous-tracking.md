# 连续估计与重投影节点（8 / 9）

## 实际执行链

像素候选检索/提取 → 模型单次选择编号 → 编号归属和同步校验 →
`spatial_localization` → `continuous_trajectory_estimation` → `reprojection_quality_check` → 绘图。

最后三个是独立的真实LangGraph节点，所有处理都在本地，不增加模型调用。

## 连续轨迹估计

基于已通过原双阵求交检查的候选段，在最多9点的重叠窗口内，以两阵**有符号方位残差**、加速度先验、超速惩罚和原始交点偏移先验进行有界Huber最小二乘。窗口重叠估计在同一已观测时刻合并；不新增时间，不修改原角度。单点最大调整受原交点敏感度与500米上限约束。

默认速度上限30m/s、加速度上限0.5m/s²、加速度先验尺度0.1m/s²、角误差尺度1°；参数是假设而非真值，.env.example列出可配置项。默认最大间隔按当前16时间切片推算，非此采样方式需显式设置TRACK_MAX_GAP_S。

候选sample_index跳号、原几何拒绝形成的间断、超过最大时间间隔、优化后超速/超加速度均断段，不跨缺测补线。两点短段不执行连续优化，明确标记short_or_unoptimized。优化不收敛时保留原交点作为回退，并记录failed_windows，仍必须通过运动与重投影检查。最多256窗口、每窗口80次函数求值，超预算报告失败，不无限循环。

使用SciPy least_squares： https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html

## 重投影质检

空间位置按同一局部切平面和平台运动模型回算到hull/tow，核对折叠角度、有符号分支、距离、绘图区边界和已锁定候选像素。

默认角度误差门限2°，像素门限为max(3px,绘图区宽度×2°/角度范围)。未通过点断段，不在最终图中连接。不足两点的段不作为轨迹绘制。青圈为投影，红叉为拒绝观测；绿圈仍表示Agent原选择，不表示通过。

报告统计角度/像素残差、拒绝数量、唯一观测保留比例；镜像分支不重复计数。比例分母是Agent已选观测，并非全场景真值时间覆盖率。敏感度字段仍来自原始射线交点，不是优化后的统计置信区间。

## 产物

- calibration_context.json：标定与本次优化参数，无密钥。
- spatial_raw.json：未优化几何候选，便于对照。
- tracking_report.json：优化窗口、短段、断段、参数和本地规则来源。
- reprojection_report.json：逐点双阵投影、误差与通过状态。
- reprojection_0.png等：原图叠加，前端可点击放大。
- tracks.json / estimated_track.png：仅保留最终可用空间候选段。

失败也保留可获得的报告，不自动付费重试。单文件绘图不走这些节点。

## 边界

这不是跨目标/跨平台全局多假设跟踪，不会自动纠正Agent身份关联或消除镜像。重投影使用与求解相同的观测和模型，不是独立准确性验证。错误候选、错误ROI和错误配对仍可能通过。

运动先验可能压制真实机动；稀疏候选、短基线、远目标和局部平面近似仍会限制定位。已用合成观测测试噪声、断段、镜像与误投影，尚无真实模型端到端准确率结论。

更新：新证据流程按像素/局部亮带误差代理进行逐点加权与敏感度检查，不再一律使用1°；详见target-count-progress.md。旧数据缺省仍为1°。
