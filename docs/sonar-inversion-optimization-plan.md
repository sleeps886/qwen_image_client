## 1. 核心决策

当前主路径是“少量彩色峰候选 → 大模型逐点配对 → 每时刻双射线求交 → 小窗口修正”。建议改为：

**渲染标定 → 相对强度恢复 → 高斯亮带测量 → 时间连续/交叉多假设 → 双阵整段关联 → 正向观测模型约束的批量轨迹估计 → 图像与方位回投验证；大模型只复核程序给出的有证据假设。**

不是继续增加提示词或节点数量，也不是只把16个时间切片加成48个。首期先建立可独立验证的数值测量与关联基线，再决定模型复核和知识库案例是否带来额外收益。

## 3. 统一正向观测模型

### 3.1 建立纯函数适配层

在识别后端新增独立的正向观测模型组件，不直接导入有全局配置、渲染或执行副作用的生成器模块。

输入仅包括受支持的平台配置、时间和待评估的候选目标位置；输出阵列位置与折叠方位。统一：

- 经纬度及局部投影约定、参考纬度和地球半径；
- 航速单位、北为0°顺时针航向；
- offset[0]沿船首、offset[1]沿左舷的阵列偏移；
- 平台固定航向、固定速度运动；
- 球面初始方位、相对航向与折叠映射；
- 时间轴方向、范围和图片实际像素坐标。

当前平台解析允许的REF_LAT/REF_LON/EARTH_R等字段不能在新模型中无说明地丢弃或采用另一套含义。缺失字段依照明确声明的工具版本配置处理；不支持或不明的配置必须告警/待标定，不能编造。

### 3.2 一致性先于优化

在独立测试中使用已知位置核对：静止/移动平台、非零侧向偏移、船首/正横/船尾、折叠边界和多时刻。测试必须区分：纯公式一致性、图像测量误差、关联错误和位置反演误差。

正确公式不能直接证明目标关联正确，但可排除坐标、单位和约定混乱。

## 4. 模型前图像信息处理

### 4.1 标定与渲染配置

建立版本化renderer_profile，描述颜色映射、dB显示范围、轴约定和是否存在理论轨迹叠加。优先使用明确的工具配置或可靠色条；不默认所有图片都是同一配色和[-5,16]dB。

绘图区检测需要同时检查两阵图及边界，并输出ROI、角度/时间像素映射、有效分辨率和异常区域。白色实线、黄色虚线若是生成器理论叠加，必须单独标记或屏蔽，不能当作从声呐强度中检测出的证据；不能仅按颜色盲删真实高亮区域。

图片缩放、色条缺失、裁剪或轴方向不明时，降低信息恢复级别或请求标定，不给出假精确度。

### 4.2 颜色到相对强度

用已确认颜色映射的查找表，将RGB映射到dB区间及颜色拟合误差，再转换为相对线性量：

```text
relative_intensity = 10 ** (D / 10) ≈ S / P0
```

注意：P0是原矩阵中位数，通常无法由PNG恢复绝对值。允许把每张图的比例因子作为未知增益；不能宣称恢复了绝对声压或原始矩阵。

处理信息损失：

- 色彩量化对应区间，不是无限精度数值。
- 达到上下显示界限的像素按截断/饱和约束处理，不当作精确值。
- 反走样、网格、文字和理论线用掩膜或低权重表示。
- 未知配色仅使用秩/形态特征备用分支，不强行套用高斯幅度拟合。

### 4.3 去背景与保弱信号

在相对强度域估计稳健背景及局部噪声尺度，采用温和的角度/时间多尺度处理。时间邻域支持作为连续分数，不要求所有邻近切片都超过门限后才保留，避免弱信号和快速机动被一刀切删除。

滤波尺度以度和秒定义，再映射到像素。不得靠图像增强生成新的亮带或用锐化结果冒充新测量。

### 4.4 高斯亮带测量

对局部时间—方位块拟合：

```text
I_a(b,t) ≈ B_a(b,t) + Σ_j A_aj(t) exp(-(b-μ_aj(t))²/(2σ_aj²))
```

其中a为阵列，B为背景，μ为中心方位，σ为宽度，A非负；中心及宽度采用跨时刻约束，边界按生成器实际截断方式处理。比较一个/多个峰的解释，结合时间证据与复杂度惩罚，不能看到一团高亮就固定拆两个峰。

输出每项测量的候选ID、时间、中心、宽度、像素范围、残差、有效噪声尺度、饱和标志、分辨性和误差代理。误差代理通过隔离合成集标定后才可作为统计量；此前不称置信区间。

可用SciPy的find_peaks做多尺度初值，least_squares做有界稳健拟合；不是把find_peaks的峰数直接当目标数。[峰检测](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.find_peaks.html)、[非线性拟合](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)

### 4.5 自适应时间网格

不再将16或48作为准确率开关。先按图像有效时间分辨率构造测量网格，再对交叉、折返和机动区域细化，对平稳段压缩上下文。

保存所有实际测量时间和来源；PNG本身没有的信息不能靠加密采样产生。优化窗口改用秒定义，目标函数按有效采样间隔/相关性加权，避免切片增多导致平滑强度、窗口跨度和断段规则一起变化。

## 5. 交叉亮带分离与数量判定

### 5.1 时间图与多假设

将测量构成时间有向图，代价包含中心变化、角速度/曲率、带宽、局部残差和出生/消失惩罚。使用有预算的路径搜索/全局关联，而不是只连接下一行最近点。

对X区域保留至少两种有证据的前后对应候选；综合交点前后的时间段评分，不能在交点直接交换身份。允许短时缺测保持身份假设，但缺测不变成新的测量。

为避免0～180°折叠处误判，应支持潜在的展开角度分支：θ=±b+360k，再由时间与空间模型约束。方位到180°后折返不等于目标突然转向或变成杂波；宽度大、直线、较弱也不是排除依据。

### 5.2 混合交点的表示

两个目标在某时刻只呈现一个不可分辨混合峰时：

- 不把一个测量重复作为两个目标的独立数量证据；
- 不强造两个观测角；
- 用“交叉混合区域”表示共同图像解释，前后轨迹延续由其他时刻支持；
- 若联合模型估计了交点位置，标为模型估计，不加入原始观测表；
- 对完全等价的解释保持未决。

### 5.3 数量是模型选择结果，不是模型口述

对候选路径集合联合考虑图像解释、持续时间、独立证据、未解释亮带与复杂度，产生数量候选及竞争解释。双阵同一目标、前后断段、镜像不相加；不能因为某条暂时无法定位就从清单删除，也不能为凑四目标强制拆峰。

可将离散归属与互斥约束建模为受限整数优化，或采用有上限的多假设搜索。SciPy milp可用于离散优化原型，但需要时间/节点预算，超时不报告为最优解。[整数优化接口](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html)

## 6. 双阵整段关联

先各阵形成带证据的轨迹片段，再提出hull/tow的轨迹级配对候选。共同检查时间重叠、曲率及折返时刻、可见时窗、几何可行性、整段拟合残差和观测独占。

不能按两个列表下标配对，也不能简单匹配最接近的角度。两阵幅度和带宽可以不同，不将亮度相同当硬条件。

候选集合之间做全局归属，避免局部最优把同一段分给两个目标。保留前若干有竞争力的解释，记录评分差和未解释观测；这些分数是排序依据，不是概率置信度。

对短视差区域先标记定位信息弱，不直接把所有相关角度丢弃；合法观测可参与整段求解。最终仍要通过可辨识性和测量误差评估，不能靠放宽距离/速度门限保证出图。

## 7. 用正向模型进行整段空间反演

### 7.1 从逐点求交改为批量拟合

为候选目标路径P_j(t;Θ_j)计算两阵预测方位：

```text
b_hat_aj(t; Θ_j) = fold(gcbearing(array_a(t), P_j(t; Θ_j)) - heading)
```

联合优化目标包括：

```text
J(Θ, association, motion_model) =
    稳健方位观测残差
  + 可用区域的亮带图像解释残差
  + 分时段运动约束
  + 模型复杂度与错误关联惩罚
```

按可用性分阶段加入图像残差，避免第一版就构造过大联合问题。首先实现带锁定关联的批量角度拟合，再与关联多假设交替优化并限制轮数。

逐点射线交点仅用于多初值及诊断。不能先因敏感而删除所有点，再只允许在错误交点附近500米内微调。新的搜索边界来自明确的空间/运动先验与多初值策略；没有收敛或信息不足时返回未定位，而非假定成功。

### 7.2 运动模型与生成器一致

- 航点型：分段匀速、允许有限个转向/停止事件；用复杂度惩罚限制过度分段。不用全程硬加速度上限否定生成器支持的立即转向。
- 曲线型：采用平滑路径参数化及适应性控制点，不将全段强制拟合成直线，也不硬编码当前参考样本的正弦公式。
- 通过当前BTR拟合、留出时段预测和复杂度比较选择模型，不看参考轨迹挑最好看的模型。

控制点、速度和转向时刻均是估计变量，不是从当前truth/meta读取。时间窗和正则权重按秒及连续目标函数离散化定义，采样密度变化后保持含义稳定。

### 7.3 折叠与镜像

不在整条轨迹上永远锁定同一左右舷符号；空间路径跨越船首/船尾轴时，折叠前符号可以改变，由连续路径和观测模型共同解释。优化实现应处理角度环绕及折叠边界，不对跨边界残差直接做错误线性相减。

若阵列与平台运动保持共线，两条镜像路径可能同样解释观测。仅凭两张折叠BTR与该平台数据通常不能保证唯一侧别。需要明确侧别、区域先验、非共线额外观测等信息才能消歧；知识库的经验偏好不能冒充新的测量证据。

### 7.4 观测与估计分离

原始角度/时间和候选ID不可改写。拟合函数生成的连续轨迹、缺测区短期预测和区间外外推单独输出，注明支持范围及先验来源。

生成器track图通常绘制全时段，而t_on/t_off只控制BTR可见性。不可见时段不一定能恢复；比较相似度时必须区分“可见区间内恢复”和“先验外推”。无法辨识的位置应保留范围/镜像/候选集，不能输出假精确轨迹。

## 8. 反向生成BTR做闭环核验

将估计的路径重新经正向模型生成两阵方位曲线和期望高斯亮带，回投当前声呐图，检查：

- 两阵观测残差、带宽与饱和区间解释；
- 未解释的持续亮带，提示漏目标；
- 预测存在却无观测支持的带，提示错误目标或过度外推；
- 交叉前后身份是否一致、竞争解释是否接近；
- 数据部分的Jacobian敏感性/可辨识性，避免把强先验造成的稳定误称为数据充分。

不要求复现随机噪声像素；背景、增益和振幅抖动作为扰动/未知量处理。不能以“重新模拟的整图像素完全相同”为验收目标。

当前数据上的回投是自洽性检查，不是独立准确率验证。留出时间行可帮助选择假设，但不能自动消除镜像或作为真实坐标证明。

## 9. 智能体职责调整

### 9.1 模型前证据包

给模型的是可读的证据，不是只有原图和几百个离散编号：

1. 原始hull/tow图及标定摘要；
2. 背景处理/亮带中心叠加图；
3. X区与折叠区的前后局部放大图；
4. 程序提出的轨迹级关联候选、代价分项和支持时窗；
5. 可选的已审核相似案例说明，与当前测量分开。

附图数量、字节和上下文预算仍受现有网关限制；按争议区域优先选取，不把全部诊断图都发送。

### 9.2 模型输出契约

模型复核程序提供的hypothesis_id/region_id及原因枚举，不再从零生成数百个候选配对，更不填写经纬度：

```json
{
  "preferred_hypothesis_ids": ["assoc_003"],
  "reviews": [
    {"region_id": "cross_002", "decision": "keep_ambiguous", "reason_codes": ["merged_peak"]}
  ]
}
```

服务端验证编号、互斥关系与证据支持。偏好的假设如果不满足数值约束不能采纳；无法提供证据时模型不得单凭“抖动/弱/直线”排除目标。程序保留合理竞争假设，不强迫模型输出唯一答案。

默认最多一次可选云端复核，只有用户授权时调用；不存在自动付费重试。JSON失败只影响该次模型复核，不破坏已形成的本地数值候选，并明确显示“未完成模型复核”。

## 11. LangGraph与前端执行过程

建议阶段：

1. 输入/平台校验与渲染标定；
2. 可选精确案例分流；
3. 颜色/相对强度恢复与背景估计；
4. 高斯亮带测量与分辨性分析；
5. 单阵路径及交叉/折叠假设；
6. 双阵整段关联与数量候选；
7. 可选案例指导和模型复核；
8. 候选运动模型的批量空间求解；
9. 正向BTR回投、未解释亮带和可辨识性检查；
10. 结果分类、来源说明和绘图。

前端展示每步真实耗时、输入/保留/拒绝数量、可点击叠加图、交叉竞争解释和估计支持时间。明确区分亮带路径、目标身份假设、定位成功数、镜像数和片段数，不用一个数字混称“目标数”。

颜色按身份固定，侧别用线型区分；实测支持段、模型估计缺口和外推段有不同标记。模型未执行、失败或被跳过必须如实显示。

## 12. 数据契约与工程改造

新增的测量、关联和估计对象分别版本化：

- BtrMeasurement：阵列/平台、实际时间、方位中心及宽度、局部像素区域、残差、质量/饱和/混合标志、标定版本。
- TrackletHypothesis：测量ID集合、时窗、交叉事件、展开角候选、竞争归属。
- AssociationHypothesis：双阵路径组合、唯一性约束、代价分项、未解释观测与数量候选。
- TrajectoryEstimate：模型族、参数/数值点、观测支持范围、估计/外推标识、数据敏感性和镜像关系。

拟新增纯正向模型、BTR强度解码、亮带拟合、路径多假设、双阵关联和批量估计组件；在现有服务层内分职责，不把所有算法塞到Agent或HTTP路由。现有旧链路保留为对照，采用特性开关灰度切换。

平台“js数据”优先规范为JSON；若是JS包装数据，只允许已有受限数据提取，不执行脚本。仿真工具的算法代码仅作为约定参考，运行时不执行用户公式/任意代码来猜目标。

| 阶段 | 工作 | 验收重点 |
|---|---|---|
| P0 基线与正向一致性 | 固定隔离样本，核对坐标/方位/折叠，拆分误差来源 | 公式及约定测试通过，建立真实基线 |
| P1 测量优化 | ROI/颜色配置、相对强度、局部多峰、饱和与弱信号 | 亮带角误差、漏检/误检与交叉可分辨性优于基线；不接云端 |

初期原型沿用NumPy/SciPy/Pillow和现有LangGraph，不因计划增加Agent就先增加多轮LLM或新服务。各阶段未通过验收不默认推广，不再只以Python测试通过宣布准确率改善。

### 13.1 必测场景

单目标直线、多个分离目标、两目标X交叉、0/180°折返、端点截断、弱目标与强噪声、两个宽峰合并、短时消失、真实航点转向、曲线机动、短基线远目标、移动平台和非零侧向偏移；另覆盖截图/缩放、缺色条和理论线叠加。

### 13.2 指标与防泄漏

- 测量：两阵角误差分布、交叉区域误差、漏检/误检、饱和比例。
- 关联：目标数误差、双阵配对错误、身份切换、未解释持续亮带。
- 定位：时间对齐后的米制位置误差与覆盖率；镜像未解比例、不可定位比例单独统计，不能只保留最好看的分支。
- 图像：回投BTR结构一致性与原参考轨迹同坐标轴下的形态对照；轮廓相似度仅辅助，不代替坐标精度。
- 成本：运行时间/内存、模型调用数、实际可得Token与费用。

先分别验证“已知关联+理想方位”“已知关联+图像提取方位”“未知关联+图像提取方位”，再做端到端，定位到底是测量还是关联/求解限制。现有生成资料可用于离线评测，truth/meta只进入评测器，不进入未知样本推断。

按场景/轨迹族分训练或标定、验证与测试集，同一路径换噪声不能当完全独立样本。数值验收门槛在基线建立后预先确定，不承诺未经测试的准确率、米数或相似度百分比。

## 14. 不能绕过的边界

1. PNG存在色彩量化、饱和及像素采样损失，不能无损还原源矩阵。
2. 两个完全重叠的峰不一定可分，前后轨迹仍可能存在等价解释。
3. 短基线、小视差情况下，连续先验能稳定估计，但不能凭空产生距离信息。
4. 共线阵列/运动的镜像可能无法仅由两张折叠BTR消除。
5. 原track图含不可见时段，不能用无观测依据的全时段补线来提高相似度。
6. 该工具合成的是简化BTR；本方案首先面向该生成分布，不声称直接适用于真实声呐回波或已经具备真实波束形成能力。

结论：优先修复测量与全时段关联/反演模型，再验证Agent与案例库的增益。目标是降低实际错误和提高有观测支持的轨迹相似度，而不是输出更像参考的无依据曲线。
