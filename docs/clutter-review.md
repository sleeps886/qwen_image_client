# 未验证杂波判定不得直接排除候选

## 问题

结果 `20261117_152109_8f05f537` 中，模型先提出四项候选，后凭直线、较弱和局部方位抖动推测固定障碍、多径等成因，将 T3/T4 标记 clutter。旧数量审核直接剔除 clutter 状态，导致候选清单显示两项。当前没有独立、经验证的杂波分类器，不能把这种模型推断当作排除事实。

## 修改

- Agent 提示词与实际检索的 `clutter-review-v1` 规则要求：不能仅凭形状、相对亮度和局部抖动排除；不得混淆方位角与仰角或编造杂波成因。
- 数量审核保留模型原 `model_status` 和 `reason`；模型 clutter 的审核状态为 ambiguous，并记录 `clutter_classification_reviews`。不根据模型自行填写的文字或字段放行“已验证杂波”。
- 前端展示待复核项。保留候选不意味着确认物理目标，不自动生成配对、修改候选编号或增加空间轨迹。
- 后续若增加独立分类器或人工复核，应单独定义可审计的输入、证据及验收标准，再引入确认排除流程。
