# Agent + 本地知识规则：阶段实现

> 更新：现已增加独立的连续估计、重投影节点，见[详细说明](continuous-tracking.md)。下方第一、二阶段的未实现项为当时基线。

## 噪声过滤更新（v2）

候选提取使用行背景中位数/MAD自适应阈值、局部背景显著性、最小峰宽，以及前后两个时间距离共四个邻近切片的支持检查。不为满足“最多6峰”强行补满候选；无可信候选则本地停止。candidate_evidence.json记录filter_version及各类拒绝数量。

阈值为工程启发式，不是经标定的恒虚警检测或统计SNR。弱目标、快速机动和短时窗端点可能被过滤；持续结构化杂波仍可能保留。需独立样本评测，不能宣称已消除所有环境噪声。

## 已实现

- 真实LangGraph预处理图：SQLite结构化规则检索 → 图像候选提取 → 观测/关联契约组装。
- 模型网关保持已有同步/SSE传输，单次调用联合完成观测筛选和关联。不是三个独立模型互相投票。
- 后处理图校验candidate_pairs；实际角度、时间来自本地候选表。禁止虚构编号、跨阵列/平台/时间配对，以及重复分配候选。
- 每图自动识别最大连续彩色区域，排除分离的色条；图片工作流默认16个同步时间切片，提取每行最多6个亮带强度区域的加权中心。48切片默认推广已撤回，可通过服务器环境变量 `SONAR_EVIDENCE_TIME_SLICES=48` 显式进行实验（16～64整数）。证据包记录实际切片数量及 experimental_density，不代表精度通过验收。
- 本地规则限定为内置、带版本的代码审核规则，不代表领域专家已经验证。按阶段/版本精确检索，不是向量RAG，不动态摄入任意文件。
- 输出候选粉点叠加、选中绿圈叠加、候选表、解析后的双阵观测、规则来源、图执行记录和质量报告。
- 同步/SSE结果均提供文件下载；失败也保留已生成证据。支持仅预检图片+platform.json，完全本地生成候选预览，不调用模型。
- 图片空间流程缺少平台时仍不能定位；完整Agent流程需要平台参数及带hull/tow标记的双图。原生成工具、单文件模式不变。

## 未实现／不能承诺

- 没有新增自动付费重试、独立诊断LLM、自动两轮自我纠错。
- 没有历史案例向量库、专家案例导入界面或在线学习。
- 已有局部窗口连续估计和重投影报告；仍无跨目标全局多假设跟踪、统计置信区间或独立真值验证。
- 没有跨请求checkpoint恢复。agent_trace是可审计执行记录，不是可恢复检查点；Graph状态中不放密钥。
- 绘图区启发式可能失效，弱信号、蓝色目标、窄时间窗与交叉回波可能漏检。叠加预览需要人工核对。
- 固定时间切片不等于完整观测；稀疏候选段不代表已经准确恢复完整轨迹。局部空间求交的物理局限不变。

## 防止数据泄漏

本流程只处理选定的hull/tow和platform.json。不读取meta、semantic、truth或参考图；知识库不包含当前样本答案。候选编号与角度由程序锁定，模型文字不作为代码执行。

## 验收

本地合成双阵图：ROI/色条隔离、方向、中心角误差、假编号拒绝、同步和归属校验、单次FakeGateway、空间绘图、HTTP证据下载。真实仿真样本：只运行本地提取并人工检查叠加，不调用云端。

尚未运行真实模型对照试验，不能声称识别准确率提高。下一步应建立隔离测试集，对比角误差、关联错误、位置RMSE、覆盖率及费用，再决定是否增加检索案例和复核调用。

## 撤回默认加密采样与绘图误导修复

后续48切片结果 `20261117_162508_2d94d633` 仍未达到要求：模型仅给2个ID、70组有效配对，身份复核拆为4个H假设、65组观测；原空间求交为14段120点，连续估计发生30次断段，重投影后最终22段97点。断段并不都是重投影造成，不能归结为最后一道校验。
