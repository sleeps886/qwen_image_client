# 聊天输入与选择区底部固定

中间列拆成上方独立滚动的chatStage与下方chatDock。消息、执行节点、空间结果在上方；已选观测展开区、问题输入、授权复选框、发送、待确认、失败恢复与绘图操作均在底部。

使用flex分配真实空间而不是position:fixed覆盖消息。底栏最大高度58dvh（窄屏60dvh），展开很多选点时内部滚动，上方消息至少保留60px。左右侧栏与原有授权/状态判断不变，无新增模型调用。

浏览器验证：30条长消息时消息区独立滚动、底栏坐标不变；展开40条选择后仍贴底且不遮住全部消息；模拟失败状态下恢复按钮仍在底部；390px窄屏边界通过。右侧栏拖动、键盘调整、宽度持久化、收起展开及选点保留回归通过。测试使用隔离服务/浏览器，不改用户已有会话。
