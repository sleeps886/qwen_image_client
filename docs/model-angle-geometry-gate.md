## 当前门槛

- 回投仅匹配该来源身份的实际支持测量。没有来源支持时不再退回全场最近亮点匹配。
- hull和tow分别至少4个有效时刻，且至少4个共同时间点；单阵不能当作双阵通过。
- 每个阵列方位RMSE均不超过1.5度，不能被两阵混合平均掩盖。
- 同时间窗内相对来源候选运动方向改变超过15度时，要求实际方位残差改善至少 `max(0.2度, 来源残差×25%)`，否则拒绝无依据旋转。并非直接旋转或强制复制来源候选。
- 门槛是工程启发式，不是标定置信度；通过仅表示观测一致，不表示真实侧别或位置精度已确认。
- 任一输出分支失败，则整次模型最终输出拒绝生成。保留原回复、用量、后端独立证据及 `model_final_quality.json`；没有本地数值替代、没有付费自动重试。
