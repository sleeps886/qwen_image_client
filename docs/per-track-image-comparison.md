# 逐轨迹图片相似度

`POST /api/compare` 保持原上传方式，新增逐条结果 `per_track`、线条数、低分阈值及汇总说明。前端在对比区显示匹配表，低分、漏检、多余线条标红；叠加图中标注 R/A 编号及红色问题线，JSON 可下载。

计算步骤：
1. 按彩色前景色相分线，过滤小标记、短图例；每张图的所有有效线共享一次整体前景包围盒归一化，禁止逐线独立移动缩放。
2. 两图各条线两两计算双向容差轮廓 F1（256×256，3像素容差）。匹配不要求颜色一致。
3. 最大总相似度一对一分配；无重叠不强行匹配。漏检和多余分别产生 0 分条目。
4. 所有条目等权平均得到整体相似度。旧的全图像素 F1 保留为 `global_outline_similarity_percent`，不再作为主分数。
5. 逐条分数低于 70% 提示检查并标红。这是 UI 提示阈值，不是经过标定的识别正确率门槛。

限制：只比较视觉轮廓，不是米制定位准确率；各图整体归一化会忽略绝对尺度及平移，不包含时间和运动方向验证。同色多目标可能被合并，短线可能被过滤。R/A 是图内从上到下的编号，不冒充真实目标 ID 或模型 N 编号。若需要真实目标逐时刻 RMSE，应使用结构化真值评测。
