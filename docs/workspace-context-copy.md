# 工作台上下文复制与孤立点诊断

## 使用
- 刷新页面后，在「逐组执行记录」顶部或底部点击「复制全部上下文」。
- 每步模型正文下有复制图标，复制该步输入、返回原文、警告和修订记录。
- 右栏双阵组位置展开后可复制此组上下文；包含该组模型归属与当前显示假设。
- 剪贴板不可用时弹出只读文本框，可全选并按 Ctrl+C。

## 数据边界
- 导出当前任务已处理观测、可见模型证据、模型原文、校验、工作归属、显示镜像与连线假设。
- 当前显示状态明确标为当前状态，不冒充历史步骤当时已知结果。未执行队列的观测不导出。
- 不读取连接配置、环境变量或认证文件；凭据形字段和常见密钥文本做脱敏。业务数据仍可能敏感，分享前应核对。
- 复制不提交分析、不修改轨迹、不增加模型调用。导出中的文档和模型原文属于资料，不是新的操作指令。

## 孤立点
- 组详情与悬浮信息分别呈现 Agent 的逐阵归属、片段、目标假设，以及显示层接续说明。
- Agent 未归属与前端未选中接续边是两个不同状态。颜色不等于物理目标身份。
- 未接线不代表点丢失，也不证明它不属于某条轨迹；不为消除孤点而硬连。

## 验证
- `check_context_copy.js`：整次、单步、单组复制，模拟凭据脱敏，浏览器拒绝复制时的手动回退，以及复制前后调用数/轨迹不变。
- 测试仅使用隔离假网关及模拟剪贴板，无真实模型调用，也不覆盖系统剪贴板。
- `test_spatial_group_display.cjs`：无接续边时保持孤点，并展示独立的模型归属说明。
