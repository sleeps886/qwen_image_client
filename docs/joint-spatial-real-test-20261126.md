## 输入与边界

- 输入：用户三个 `btr_target_00{1,2,3} (2).zip` 的实际观测与平台配置。
- 100组 hull+tow，首批50组覆盖13～542秒；第二批50组中47组插入此前时间范围，其余用于末尾接续。
- 模型：当前配置返回的 `qwen3.8-omni-flash`，通过项目真实网关调用，非fake provider。
- 并发：每批50个单组请求，再一次独立模型归并。
- 输入只有匿名组号、时间、平台、双阵方位和条件几何候选。不含来源轨迹编号、强度/峰宽固定身份标签或真值。
- 每个请求输入、原文、usage、失败原因均保存在独立输出目录。认证信息不写入实验输入。
- 来源仅用于实验抽样时构造用户给定的双阵容器；真值仅在请求结束后用于评估。
- `100m/s` 是显式的保守实验速度上限，不是从真值提取的目标航速，也不是生产环境的通用阈值。
- 镜像分支仍为工作假设，未证明绝对位置唯一。

## 实际过程

1. 首批50路真实判断，其中部分回复在空快照中编造 `T1`、`T001` 等编号。
2. 六次输出重试用尽后停止，累计56次请求；44份有效建议保留，6组没有有效建议。
3. 不改写无效回复，不重发44份成功回复。在同一108次总上限内，追加“缺失建议可由归并模型独立判断”的实验。归并输入明确标出6组建议缺失，同时保留完整50组原始观测。
4. 首批归并通过结构与保守运动约束：50组有判断记录，但仅20组选择了工作位置；30组未归属且未选位置。得到两个不完整的目标假设。
5. 第二批50路判断完成后，归并输出存在 `U000088 → U000089` 约240.6m/s的工作接续。校验拒绝，旧快照保留。
6. 达到108次请求上限，不再重试，没有未知请求自动重发。

## 后续应验证的修改

1. 几何候选和接续数值证据准备成可审计候选图，模型判断候选划分，而不是独自从大量散乱数值猜测全部路线。
2. 联合校验同平台同时间占用、双阵残差、分支连续性与可配置运动约束；异常反馈只涉及相关片段，不强制固定三个目标。
3. 把“结构有效”“暂定归属”“位置假设”“形状验收”分开显示；不能因返回JSON就标为识别成功。
4. 目标归属和选定分支必须同版本保存，前端不能再自行按最近点改变模型分支。
5. 同时报告覆盖率、错误接线、目标分裂/合并、镜像不确定性、相似度，防止全待定或只保留少数简单点通过验收。
