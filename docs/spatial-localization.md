# 双阵空间候选轨迹

图片模式现在只以空间定位为最终绘图目标。生成工具和单文件绘图不变。

## 数据流与契约

`prepare_input → 大模型读取hull/tow → dual_array_bearings → solve_spatial → lon_lat → render_tracks`

模型每条tracks包含id、branch、platform_id；每点包含t、hull_deg、tow_deg。模型负责同目标同步配对，不直接输出距离或经纬度。后端强制替换旧默认契约；无有效双阵观测时不给替代图。

同一样本的input/platform.json提供位置、航向、航速和两阵偏移。偏移按生成器约定：第一维船首向前、第二维向左舷。平台采用恒定航向、恒定速度；局部切平面以第一个平台初始位置为原点。

## 安全边界与局限

- 独立求解四种左右舷组合；保留可行镜像分支，不用真值挑选。候选分支不能算成多个目标。
- 排除小于1米基线、近似平行（交角不足1°）、反向及超过100公里的交点。
- 对每阵角度分别扰动±1°；交点失效或位移超过距离50%/5000米（取小者）则拒绝。该敏感度不是统计置信度，1°为保守应用假设，未经数据标定。
- 拒绝点切断当前分支；单点不成轨迹，不跨拒绝点补线。不使用插值制造观测。
- 这是局部平面几何估计，不是完整球面声传播反演；远距离、极区、阵列几何误差、大模型错误配对会影响结果。尚无自动跨平台融合或唯一镜像消歧。
- 历史bearing_time结果仍可读取，但新图片请求不再用它冒充空间输出。

## 验证

合成已知位置生成双阵角度，验证位置与镜像恢复、运动和偏移旋转、并行拒绝、无平台/坏点/直接位置JSON拒绝，以及本地PNG和HTTP集成。真实模型识别准确率仍待授权实测；不承诺复现仿真真值。
