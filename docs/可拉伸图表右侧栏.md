# 可拉伸图表右侧栏

将综合方位—时间图与已勾选点来源颜色预览从聊天区搬到独立右侧栏，保持原DOM编号与事件绑定，不复制图表、数据或会话。中间仍是聊天、执行节点与授权表单；右栏独立滚动。

- 拖动右栏左边缘调整宽度，限制范围为280px至可用宽度（最高900px），为中间聊天区保留空间。
- 分隔条可聚焦，方向键调宽，Home/End到边界，双击恢复460px默认；宽度仅保存为浏览器UI偏好。
- 顶部“图表侧栏”可展开/收起，不改变当前选择、后台任务或模型结果。
- 窄屏不压缩中间聊天区，使用可开关右侧抽屉；宽度随窗口约束，不溢出屏幕。
- ResizeObserver在侧栏宽度变化后重绘SVG；保留20组/40条观测、每图20个标记、来源连线、悬浮去重JSON与键盘查看能力。

验证：1800px视口下两图均在聊天右侧；鼠标拖动、方向键调整、宽度刷新恢复、收起再展开保留选择通过；700px下抽屉开关与宽度边界通过。真实三个ZIP双阵成组选点与悬浮详情回归通过。布局与选点不发送API，不调用模型；JS语法及diff空白检查通过。
