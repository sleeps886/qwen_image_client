# 稀疏观测、未归属与空空间图修正

日期：2026-11-25；仍在原`/incremental`工作台实施。

## 实际案例核对（只读）

用户这轮提交20个独立观测：11个hull、9个tow，20个不同时间，没有严格同步时刻。模型将9个tow点归为3个单阵片段，11个hull全部明确留在unassigned。关联本地warnings为空，因此不是本地规则又过滤了11点。3个片段不等于3个物理目标；本轮target_hypotheses为空，空间参考为insufficient_joint_identity。

第二次绘图回复没有空间坐标，属于“尚无验证空间候选”，不是已经有坐标但画布丢失。原模型回复、调用次数、已采用结果均未改写，未重新请求真实模型。

## 已修正

1. 绘图原用同平台同阵所有已提交点的最小间隔×3，混合片段最小间隔21秒，3个片段都被套上63秒。改为各片段自身正间隔的稳健下中位数×3，附带原始间隔、未标定及仅用于分段显示的说明。不是身份否决条件，不单因稀疏推翻全部片段。案例3片段下一次准备对应399/1212/648秒；它们仍不是物理定律或可靠身份结论。
2. 关联输入增加候选覆盖信息，明确没进入R参考的点仍须与实际历史比较，可按真实行号自组暂定片段；不能只复制有R的阵列，也不能为提高覆盖强配。
3. 页面区分提交、接入、未归属、待决和未提交点，显示hull/tow接入比例、严格同步数，以及模型明确未归属/本地退回的来源。旧记录可只读生成诊断，不追改结果。
4. 空空间结果区不再整体隐藏，显示当前缺项和“尚无空间解”；之前已验证空间版本可明确标为历史版本保留，不冒充本轮结果。
5. 免费绘图预览返回空间候选能力。当前工作台明确请求空间时，空候选在前端禁用发送、后端再次拦截，不增加模型调用。实验旧API未声明purpose的兼容行为保留；当前前端始终明确传purpose。
6. 方位诊断须用户另选用途并重新勾选费用同意。返回的模型拟合/预测单独显示，来源和实际支持点区分；没有曲线时只展示实际点，不用本地线性补画，也不作为空间路线交付。
7. 新增可选“补选真实邻域并准备复核”：同平台前后各2个真实时刻的候选，先展示将增加的数量并确认，保留原选择，不用来源文件当身份，不生成测量，不自动请求模型。原20点稀疏实验可不改变。

## 用户下一步

结束当前任务后重启后端、刷新原页面。可先查看这轮诊断，再按需要补选真实邻域，免费准备并核对实际数量/字符量，最后自行授权关联复核。待形成有证据支持的跨阵目标后再申请空间图；仅想看方位趋势时必须明确选择“仅方位诊断”。

旧记录不会因为升级自动变成空间图。没有严格同步不代表永远数学不可定位，但当前正式空间路径仍需要验证过的跨阵身份/几何支持；本次未实现或宣称验证了异步空间求解。
