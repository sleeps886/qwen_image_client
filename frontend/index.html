建议选择 input 下的 hull / tow 图片。无刻度原图按工具默认标定识别：横轴0～180°、时间0～600秒（从下到上）；非默认范围请附同样本的 input/platform.json。空间定位请附同一样本的input/platform.json；大模型提取同步双阵方位，程序求解空间候选轨迹，定位不足不生成替代图。不要上传 truth、meta.json 或 semantic.json。
